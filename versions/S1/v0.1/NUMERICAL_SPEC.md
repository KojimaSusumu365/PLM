# S1数値仕様

## 1. 何を拡散するか

凍結P1が生成するD=2048の複素重畳信号xを運びます。subject/objectだけでなく、述語・否定・仮定・隔離・applied・任意のtarget_clauseを符号器に残します。SS側はその2048成分の意味を解釈せず、数値として運びます。

成分jに対して、長さL=4の公開決定的符号s[j,k]を使います。各行に+1と−1を2個ずつ置く平衡符号です。SHAKE256からのバイト列を安定ソートして配置を決め、Pythonのhash()や未知の乱数状態に依存しません。

```text
payload[j*L+k] = x[j] * s[j,k] / sqrt(L)
sum_k |s[j,k]/sqrt(L)|² = 1
```

反復対照ではs=+1。直接参照ではs[j,0]=sqrt(L)、残りを0にします。したがって3方式とも、拡散前後で各成分のエネルギーは同じです。直接参照は空き時間を含み、最適な非SS通信方式を代表すると主張しません。

## 2. チップ・時間・エネルギー予算

| 区間 | チップ数 |
|---|---:|
| 前ガード | 16 |
| 前パイロット | 128 |
| データ（2048×4） | 8192 |
| 後パイロット | 128 |
| 後ガード | 16 |
| 合計 | 8480 |

人工チップレート8000 Hz、サンプル間隔1/8000秒、捕捉窓は1.06秒です。これは数値チャネルの時間軸であり、実際の無線機の時計ではありません。

総送信エネルギーE=57344を3送信方式で揃えます。ガードの送信振幅は0です。パイロット振幅Aとデータgainは次のように定めます。

```text
A² = E / (D L + 2 P)
pilot_energy = 2 P A² = 1737.696969...
payload_energy = D L A² = 55606.303030...
gain = sqrt(payload_energy / ||payload||²)
```

パイロットはチップ数の約3.02%、送信エネルギーの約3.03%。ガードを含む非データ区間は288/8480、約3.40%です。パイロットを無料で外付けしません。全方式のピーク電力も記録し、直接参照はデータが短い分ピークが高くなる点を隠しません。gainは送信側が信号ノルムから計算する公開スカラーです。

## 3. 人工チャネル

受信窓長は固定の8480サンプル。整数遅延はゼロ埋めでシフトし、循環させません。範囲内の遅延はガードで吸収します。捕捉窓の時刻t[n]=n/Fsに対し、位相は `phi + 2π f t[n] + jitter[n]` として付加します。

複素AWGNは実部・虚部それぞれnoise_std/sqrt(2)の標準偏差。noise_stdは正規化後のチップに対する絶対RMSです。観測マスクはチップ単位。未観測値は0にし、元信号を隠し領域に残しません。限定したDC干渉の試験では、受信後に定振幅の複素toneを足します。

真の遅延・位相・周波数・乱数seedは評価側の記録にだけ置きます。受信器はこれらを引数やパケットから取得しません。

## 4. パイロット同期

前後で異なる公開±1パイロットを使います。受信器が探索する整数遅延は−8〜+8チップです。各遅延候補で前後パイロットの正規化複素内積の絶対値を計算し、低い方を候補のスコアにします。

各ブロックの観測が16未満、最良スコアが0.70未満、または2位とのスコア差が0.15未満なら保留します。真の遅延ではなく、最良候補の遅延を使います。

前後の複素内積z0,z1と、実際に観測したパイロット位置の平均n0,n1から小さな一定周波数ずれを推定します。

```text
f_hat = angle(z1 conj(z0)) Fs / (2π (n1−n0))
phi_hat = angle(sum_observed_pilots(y[n] p[n] exp(−i 2π f_hat n/Fs)))
```

推定周波数が事前範囲±0.20 Hzの外なら保留します。範囲内なら捕捉窓の時刻で周波数と位相を補正してから、推定した整数遅延を戻します。順番を逆にして遅延分の位相を誤って扱わないようにしています。

この推定は小さな一定CFOという事前条件を使います。パイロット中心の間隔8320チップに対応する周波数周期は約0.961538 Hzです。範囲外のずれはその周期で折り返し、範囲内に見えることがあります。例えば約1.061538 Hzは約0.1 Hzに見えます。パイロット相関だけでこの曖昧性を完全検出できません。実際にaliased_cfo条件で測定します。

## 5. 逆拡散と欠落

補正後のデータ部をD×Lに戻し、観測されたチップだけで成分を推定します。

```text
x_hat[j] = sqrt(L) sum_k(m[j,k] y[j,k] s[j,k])
           / (gain sum_k(m[j,k] |s[j,k]|²))
```

分母が0ならそのP1成分は未観測です。観測値が数値0であることと、未観測であることは区別します。SSと反復は少なくとも1チップがあれば推定できます。直接参照は最初のデータを持つチップが必要です。

観測するチップ数が成分ごとに違うため、逆拡散後の雑音分散も異なります。P1の判定器は変更せず、この不均一さを含めて実験的に評価します。理論上の誤受理率保証は付けません。

全Lチップを観測する場合、SS・反復・直接参照の逆拡散重みの二乗和は同じ1/gain²です。したがって同一エネルギーの白色雑音に対し、SSだけに無料の利得はありません。平衡符号によるDC干渉の打消しや、消失の分散とは分けて考えます。

## 6. 評価と主張の限界

未知評価は8符号seed×4チャネルseed。各条件・各方式に主語/目的語の正例256照会、出来事なし/真値候補なしの負例512照会です。12条件×5方式、さらに7-slot全体の別評価を行います。条件・seed内で共有する信号があるため、照会数を独立標本数と見なしません。

受入範囲はnominal、phase_only、integer_delay、small_cfo、combined、partial_combinedです。全観測・無雑音は全回復/負例誤受理0。その他の主条件は回復95%以上、誤受理2%以下、整数遅延の全試行一致、最大CFO誤差0.025 Hz以下、最大位相誤差0.15 rad以下とします。

tone・パイロット欠落・観測不足・範囲外遅延・周波数折返しは別の失敗側試験です。推定器がalignedを返しても真の同期が正しいとは限りません。評価者の真値との比較、NMSE、P1回復/保留を分けて報告します。

成分NMSEは復元できた位置だけで計算し、カバー率を必ず併記します。出力がない場合をNMSE=0としません。DFT帯域比は無雑音の離散列の計算例に限り、RF帯域や法規適合の測定ではありません。
