# v0.11 技術仕様

## 1. 目的と位置付け

Claudeの脳基板案と、その後の加算／結合比較の提案を受けた工学的な対照実験。脳の生理学的モデルを実装したものではない。v0.10を置換せず、言語用の部品に必要な「役割の区別」「組合せ依存」「部分手掛かり」「不確実な確定」を記憶単体で評価する。

v0.10の全体停止型の候補上限対策は変更しない。v0.11でも候補上限超過は確定禁止。候補数を増やして回答率を改善する実験ではない。

## 2. 表現と学習

特徴は1〜6項目、値は学習在庫内の文字列。各 `(field, value)` に、seedとSHA-256で再現されるD次元単位複素位相符号 `a(f,v)` を割り当てる。fieldを含めるため、役割の異なる同じ値を同一の原子符号にはしない。

保持する項集合Tは次の三通り。

| 方式 | T |
|---|---|
| additive | 選んだ各特徴の単項 |
| product | 選んだ全特徴の一つの積 |
| hybrid3 | 選んだ特徴の1項・2項・3項の全組合せ |

6特徴なら項数は6、1、41。hybrid3で評価正解から有効な組合せだけを選ばない。事前固定の3次までの展開であり、自律的な結合細胞の発見ではない。

```text
b_t(x) = product_{f in t} a(f, x_f)
phi(x) = sum_{t in T} b_t(x) / sqrt(|T|)
W_y = mean_{training i with label y} phi(x_i)
s_y(q) = Re[ conjugate(W_y) dot phi(q) ] / D
```

クラス別の独立した位相平均を記憶し、相関で照会する。v0.10のバンク化・対証拠付き記憶とは異なる独立した比較用実装である。全ラベルを一本のHへ圧縮した方式でもない。クラス数Cの重みは候補一つあたりC×D複素係数。学習観測は重複も頻度として保持し、クラスごとの件数で平均する。多数クラスの事前確率をそのまま採用する処理ではない。

通常の制御として残るものは、初期特徴、符号帳とseed、クラスラベル、平均用の件数、特徴部分集合の列挙、検証損失、候補管理、確定規約。勾配最適化、ID3、最終評価ラベルを使う選択はない。

## 3. 記号的対照

同じ項 `(t, values)` を明示的なone-hot特徴とみなし、各クラスの出現回数を格納する。照会スコアは項ごとの一致回数をクラス学習件数と|T|で割ったもの。

```text
K_exact(x,q) = number of identical (term, term-values) / |T|
s_y(q) = mean_{training i with label y} K_exact(x_i,q)
```

これはランダム位相の異なる項同士の内積をゼロとした期待カーネルに対応する。有限DのSSでは項間干渉がある。exactは通常の記号的方式であり、SSの精度上限を普遍的に保証するoracleではない。真の依存特徴や未観測の正解は格納しない。

exactの記憶量は実際の整数カウント項数とJSONメタデータで報告する。Dや数値信号の座標は持たないため、数値欠落実験を同じものとして捏造しない。同じDは同じ全RAMを意味しない。

## 4. 特徴選択と受理

`off`は全6特徴のまま。`validation`は全ての非空特徴部分集合を、その表現方式・backendで別々に学習・採点する。訓練と選択検証の損失が共に0.25以下、最良の選択検証損失と同率、その中で最少特徴数の候補を残す。損失は `(誤答 + 0.5×保留) / 要求数`。

最大4候補を独立保持し、5以上なら4候補だけで一致しても確定しない。支持候補なしは完全特徴の診断用モデルを保存するが確定禁止。`off`の選択検証損失は診断値として計算するだけで、モデルの選択・重み・指紋に影響しない。検証ラベルは重みへ直接加えない。

学習在庫にない値を含む選択検証入力は保留として損失へ数える。calibrationでも未知値による拒否を保留として扱い、検証・calibrationから学習在庫へ値を追加しない。最初の凍結実行はこの場合に例外終了したため、境界処理を修正し、新しい凍結で再実行した。経緯と修正前コードは `verification/failed-freeze-1/` に保存した。

各候補は最大スコアが正で、次点との差が0.02以上のときにラベルを出す。差は10桁へ丸める。全候補が同じラベルを出し、候補群が支持され、最小の候補差が追加閾値以上なら確定する。候補のスロットを混ぜない。これは確率ではない。

追加閾値は別の完全入力・正しい教師によるcalibration集合で選ぶ。経験的な受理誤答率0.1以下となる閾値のうち回答数が最大のものを採り、正の回答数で満たせなければ全保留にする。欠落や相関変化に合わせて再調整しない。有限標本の経験的目標であり、外部のリスク保証ではない。

選択は指定Dで行う。固定総係数実験の最終重みは `128*floor(D / 候補数 / 128)` 次元で再学習するため、選択時と実運用のDが異なる場合がある。実際のDと候補数を記録する。

## 5. 二種類の不足

### 意味的な不足

一特徴を削除した文脈と、全特徴なしを照会する。欠けた特徴を必要とする積項は作らず、残る項だけを加算する。正規化の|T|は完全入力時のままにする。productは一つでも必要特徴が欠ければ項がなく、保留となる。additive／hybrid3は残る項で照会し得る。

評価側は、欠けた値を全て補ったとき成立するラベル集合を、独立した完備化表で求める。可能なラベルが一つなら正答／誤答／保留を採点。複数なら、どの一ラベルへの確定も根拠不足の誤確定として数える。元の隠れたラベルに偶然合っても正答にしない。完全な意味構造を補った文章を生成する実験ではない。

### 数値信号の欠落

完全な文脈を符号化した後に、候補ごとに同じ規則で選ぶ座標を消す。観測率1、1/2、1/8、0。中間観測率では独立な二つのマスクを使う。分母は観測座標数とし、ランダム座標観測に対する相関推定を行う。全消去は保留。

`observed`マスクは外部から与えた補助情報であり、ゼロの信号値から欠測を推測していない。これはP1に向けた数値部分観測診断であり、既存P1コードやS1のチップ列、周波数・時刻同期を呼んだ接続試験ではない。

## 6. パケットと隔離

パケットは `schema / model_fingerprint / members / eligible_for_inference`。各memberは `id / real / imag / observed / available_terms`。原文、文脈、クラスラベル候補、正解、完備化表は入れない。`available_terms`は符号化器からの項数情報であり、暗黙に復元した意味情報ではない。

schema、モデル指紋、候補ID、次元、数値の有限性、bool型観測マスク、消去座標がゼロであることを検査。モデル更新・閾値調整後は指紋が変わり、旧パケットを拒否する。`encode`や数値復元だけで真実性を保証しない。暗号的な送信者認証・敵対的偽造耐性を主張するものでもない。

学習は `training.py` に分離し、評価器・旧重みなしの環境で再学習する。復号専用環境ではtraining.pyと全コーパス・評価器を除き、数値パケットだけを渡す。誤確定抑制とR1推論許可は別であり、常に `eligible_for_inference=false`。

## 7. データ・再現性・費用

依存課題5族×2置換、主客交換と肯否・仮定の構造化課題各1、少標本の5課題、相関で区別できない2課題の追加教師前後を使う。主客・markerは事前に項目化した入力で、自然文からの特徴抽出ではない。

標準は24訓練、16選択検証、8calibration、16最終評価。少標本は訓練のみ8。曖昧性は8/4/4/8、追加教師は別の8例。四集合と追加集合の完全文脈を分離する。開発／評価の課題は別seedで生成するが、同じ有限語彙・真理値表の構造を使うため、異なる自然言語ドメインへの汎化とはしない。

意味不足の完備化表は評価にのみ存在し、学習器へはcontext/labelの対だけを渡す。情報量を増やす教師付き選択と、表現方式の効果を別の軸で報告する。

SSは512/2048次元×二符号。exactは次元・符号で重複実行しない。同数回答の補助比較はD2048第一符号とexactについて、選択有無ごとに六方式を揃える。固定ハッシュ順で正解を見ず受理回答を間引く。同じ入力ではなく同じ件数で、共通回答数0は比較不能。

ソース・条件・データを本評価前に凍結し、全数値実行を二回比較する。時刻・wall timeは結果digestから除く。各方式の重み配列、カウント数、メタデータ、符号帳配列、学習時項キャッシュと所要時間を区別して報告する。単一の全RAMや電力の同一予算を主張しない。

## 8. 未実施

新しい日本語読解・生成経路への採用、v0.10の過剰保留修正、量子化、疎化、スパイク／STDP、固定7スロット、P1/S1通信統合、R1推論開放、Linux実機は範囲外。SS独自の優位性や脳の再現は、結果が出る前にも後にも自動的には主張しない。
