# コーパスと評価範囲

`data/GUARD_CORPUS.json` は開発8文書＋評価8文書、合計16文書。各splitは焦点4、既存場面2、後続教師2である。焦点の初期値と訂正値を合わせると24場面変種があり、過去の5,307場面指紋と重ならないよう生成した。

生成スクリプトは `evaluation/guard_cases.py`。事象IDと時間関係を落として事象内容をソートした粗い指紋で除外する。したがって表現順だけの変更等は新規と数えない。開発と評価も同じ除外集合で分離する。

全て既存語彙・既存文法の2事象。新語・新文法の学習、無教師での事実獲得、自然文書コーパスへの一般化ではない。焦点場面では2対象の初期値と訂正教師が異なり、古い値を支持する記憶があっても正しい訂正を取り込めるかを調べる。

主比較は評価用の4焦点×3seed×7条件×4方式=336更新試行。各試行で更新直後の対象、後続2教師の学習後の対象、既存場面1件の計3照会を行い、計1,008文書照会・2,016出力要求。既存場面は2件から固定順で選び、全旧記憶を毎試行列挙する試験ではない。

外部教師の文章を既存L1で読み、意味信号を既存P1/S1で送受信する。主比較の外部通信は正常条件。各splitの8文書について初期・訂正・照会の24受信を一度作り、全方式へ同一の受信結果を渡す。方式間で独立した通信実験を24×方式数行ったとは数えない。

別枠で、前版の3件の雑音更新を保存係数まで完全に再現する。旧焦点12場面を、直後と新しい後続教師2件の学習後に照会し、正常更新対照も同じように評価する。3seed×2更新条件×2段階×12=144照会・288出力要求。旧係数と元の更新記録は `data/CORE01_*` に同梱する。この追跡を新規場面の一般化成績へ混ぜない。

正解データは評価器だけが使う。推論の隔離検証では `data`、`evaluation`、専用学習モジュール、教師文書を置かず、モデル、保存記憶、値を持たないpendingフラグ、scopeと数値照会だけで生成または保留させる。
