# 二事象信号の仕様

## 結合と復元

事象iの枠は `F_i = P + Σ_r R_r * V(value_i,r)`。Pは存在信号、Rは五つの意味役割、Vは候補値の単位複素位相符号。事象の提示位置0/1に別の符号B_iを割り当て、標準信号を `z = (B_0*F_0 + B_1*F_1)/sqrt(2)` とする。存在信号を含めて十二成分を一つのD次元信号に重ねる。保存する二事象一覧や全文対応表ではない。

復元は各事象のBと役割Rを使う相関照合で行う。コードでは `B_i*R_r*V` を前計算した基底との相関を使い、B_iの共役で取り出してR/Vと照合する式と同値になる。元信号の1/sqrt(2)を相関時に補正する。存在相関0.65以上、候補首位0.65以上、次位またはゼロとの差0.25以上を要求する。両事象を再符号化した信号との相対L2残差が0.20以下でなければ保留する。閾値は評価前に固定する。

一方の主語が他方の目的語であっても、事象位置と文内役割を別々に結合する。二つの内容が完全に同一でも、二回の提示を二つの位置に保持し、重複除去しない。否定や仮定は各事象の独立したスロットであり、二文全体を一括して否定・仮定にしない。

この照合は受信内容の内部整合性の検査で、元の文章に対する意味的真実や改竄防止の証明ではない。別の有効な意味へ再符号化された信号は、別の意味として受理される。意味正答は評価専用の独立文法で採点する。

## 読解・生成の境界

読解：二文を明示的な句点で分割し、v0.6読解器でそれぞれを読む。一事象の信号から得た内部候補を新しい共有信号へ結合し、両方の候補に復元できることを検査してから受理する。外部の評価正解はこの検査に与えない。

生成：共有信号から両事象を復元する。その結果をv0.6の一事象信号へ内部で再符号化し、学習済み部品生成器で二文を作る。原文・読解トレース・評価正解を入力しない。二つ目の生成が失敗した場合も、第一文だけを成功として出さず全体を保留する。

転送schemaは `plm-two-event-signal-v1`。許可するフィールドはschema/model_fingerprint/dimension/real/imag/eligible_for_inferenceのみ。Dは128～16384の128倍数。event_count=2はモデル仕様に固定し、照会ごとのメタデータで意味や境界を運ばない。旧版や別mode/seed/modelのパケットを拒否する。

モデルは新しい事象コードのseed/D/mode、提示順のみという解釈、固定受理規約、およびv0.6部品モデルのfingerprintから識別する。部品モデルは併せて保存する。モデルhashは取り違えや偶発的変更の検査で、暗号署名ではない。すべての出力で `eligible_for_inference=false`。

## 学習と既存版の扱い

部品は旧版と同じ単一事象432対・初期語彙、8192次元、banked-evaluation-0、split_proofで学習し直す。二事象の例、評価語順ラベル、操作列は学習入力ではない。四つの評価seedで変えるのは新しい事象コードだけで、部品重みは固定する。

二事象の分割規約・符号結合・生成順の制御は今回の手設計。二文から構造を学ぶ段階、代名詞解決、因果推論、複数文計画まで到達したと表現しない。v0.6のバンク負荷集中の弱点と、通常Pythonによる依存特徴選択は変えていない。

## 対照・評価

開発／評価それぞれ72の順序付き意味対、四つの入力文内語順で288文書を用意する。九カテゴリは、別々の登場人物、共通主語、共通目的語、役割連鎖、主客逆転、肯否の違い、仮定の違い、同じ事象の二回提示、述語の違い。開発／評価の順序付き意味対は重ならない。評価の第一事象の主語・目的語・述語の組は部品訓練にない。第二事象は変換によって既知の組になる場合もあり、両事象の全要素がすべて新規とは主張しない。

通常評価は二方式×四事象seed。各条件で読解288、直接生成72意味対×4語順=288、往復288入力×4語順=1152を試す。独立採点器で、両事象の五スロット・提示順・各文の出力語順を確認する。評価器は旧版の制御文法を使い、新読解器による自己採点ではない。新しい組合せの人工文書であり、新規自然文コーパスとは区別する。

`partitioned` は二つのD/2幅に枠を別々に置き、総係数数Dを揃える。`unbound` はB_iを外すので、異なる事象の順序を交換しても完全に同じベクトルになる。この情報消失を直接比較する。partitionedでも成功した場合、それはSS重畳だけの唯一性・優越性を示さない。相関基底を含む全ランタイムのRAM/速度は一致させておらず、予算一致は数値ペイロードの係数数だけ。

別試験でD=128/512/2048/8192と数値雑音を測る。低次元での保留・誤復元も記録し、標準条件の成功に混ぜない。雑音は評価意味から直接生成した共有信号に加える相対L2摂動で、S1通信路やP1観測マスクの実装ではない。時系列、原因結果、代名詞、省略、自由長文への接続は次段階。
