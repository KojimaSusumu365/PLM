# v0.6 検証範囲

## 固定と保存

116単体試験と開発用比較の後、ソース・モデル・データ・学習済み選択器・評価条件を [FREEZE.json](../evaluation/FREEZE.json) で固定しました。評価結果を見てからの閾値変更・教材差替えは行いません。例、文書、事後集計用の監査コード、生成した結果は固定対象外で、最後に全ファイルを `RELEASE_MANIFEST.json` で別途封印します。

[PRESERVATION.json](PRESERVATION.json) はv0.5の463ファイルとZIP、およびコピーした85ファイルの不変性検証です。言語モデルとv0.5生成受理条件を変更していません。

## 基本試験・コーパス

- [TESTS.json](TESTS.json)：固定前の116試験。既存86件＋新規30件。
- [FINAL_TESTS.json](FINAL_TESTS.json)：固定後の再実行。
- [DEVELOPMENT.json](DEVELOPMENT.json)：6文書・3方式・2記憶構成の開発確認。主評価に含めません。
- [DATA_AUDIT.json](DATA_AUDIT.json)：1,430エピソードと過去2,431指紋の重複監査。行順を固定して保存。
- [TRAINING.json](../training_results/TRAINING.json)：576教師例・6,912更新の選択器学習結果。
- [SELECTOR_RETRAINING.json](SELECTOR_RETRAINING.json)：別ディレクトリで教材構築と選択器学習をやり直した全ファイル一致比較。時間ファイルのみ除外。

試験にはSS係数消去、選択価値学習、入力・正解特徴の拒否、古い質問・不正対象・誤ったモデル係数の拒否、予測を教師にしないこと、生成条件を選択器が迂回しないこと、回答パケットを冷間照会へ持ち込まないことを含みます。正しい形式の誤教師は学習されることも、明示的に試験しています。

## 全評価と事後監査

[INDEX.json](../results/INDEX.json) は全108条件の索引です。[SUMMARY.json](SUMMARY.json) に記憶方式・負荷・方針ごとの集計と、対応する各条件の勝敗を残します。[FAILURES.json](FAILURES.json) は誤った生成の全件です。保留は集計と条件ログへ残します。

[LOG_AUDIT.json](LOG_AUDIT.json) では648件すべての外部確認を確認しています。6回の等予算、同一対象を再選択していないこと、改訂・記憶ハッシュの連鎖、外部回答が要求対象の値であること、非対象不変性、1,296遅延照会に確認済み履歴がないこと、学習用・評価用IDの分離を検査します。

必要な確認と、すでに支持が十分な場合の任意確認を分けて数えます。正しい意味パケット、実際の生成成功、表現の指定、独立パーサの意味一致、生成文の再読解を区別して集計します。独立場面24件の繰り返しであるため、1,296を独立標本とみなす有意差検定は行いません。

## 再現性と再実行

[REPEATABILITY.json](REPEATABILITY.json) は別ディレクトリで全108条件を最初から再実行した全結果の一致比較です。時間ファイルだけを除きます。

[VERIFY.json](VERIFY.json) の再実行は次の範囲です。

- 基底SS記憶36件を読み込み照合。
- 全108条件について、6回の選択・外部確認をすべて再実行。計648回答。
- 即時意味判定と確認後の保存SS記憶108件を照合。
- その後の新規背景64件×2更新も再実行し、最終保存SS記憶108件と一致することを確認。
- 全文書の遅延SS対象照合を比較し、各条件の最初の文書、計108文書は数値パケットから実際に2表現を再生成。
- 同梱した参照数値配列はすべて再計算して完全一致を確認。
- コーパス再構築と、選択器の再学習結果を照合。

これは全文書生成を3回目に全件実行するものではありません。全評価2回の一致に加え、全選択・内容更新と選択した文書生成を再検証します。

## 推論分離・CLI・費用

[ISOLATED.json](ISOLATED.json) は教師データ、読解器、評価器、および専用の学習・フィードバックモジュール（`training.py / learning.py / feedback.py`）を置かない最小フォルダでの別プロセス実行です。固定した条件と場面から、SS選択器による次の質問の選択と、2事象・3事象それぞれの冷間生成を行います。生成できた件数は結果のまま記録し、成功場面に選び直しません。すべてのプロジェクトモジュールが最小フォルダ内から読み込まれたことを検査します。

実行結果は質問選択が一致、2事象が生成、3事象が `event:0/object` の再確認待ちでした。2照会すべての生成成功ではありません。

厳密には、継承した共用ファイル `component/algebra.py`、`projection.py`、`banked.py` には `learn`、`fit_memory`、`fit_banked` などの学習補助関数の定義も残っています。推論ではそれらへ教師を渡さず使用しません。証跡の `teacher_learning_reader_evaluator_absent` は上記の専用モジュールと教師・評価データの不在を指し、全ファイルからあらゆる学習関数の定義を除去したことまでは意味しません。数値推論と局所信号補完に必要な共用コードは含まれます。

[CLI_WORKFLOW.json](CLI_WORKFLOW.json) は読みやすい別枠デモで choose → confirm → 新規session → generate を4つの実プロセスで試した記録です。質問の選択と回答を別処理にしています。

[COMPUTE_COST.json](COMPUTE_COST.json) は固定した12文書・6確認のラウンドに対し、内容SSの照合呼出しと選択器の予測呼出しを計測します。読み込み・後続背景・文章生成を除き、各方式1回ウォームアップ後3回の時間を測定します。共通候補走査は対照方式でも数値特徴を計算しています。選択器だけの追加係数・符号基底費用も記録します。この小規模測定を一般的な速度優位性とは解釈しません。

[ENVIRONMENT.json](ENVIRONMENT.json) にPython、NumPy、OS、スレッド設定、学習・評価の時間を記録します。
