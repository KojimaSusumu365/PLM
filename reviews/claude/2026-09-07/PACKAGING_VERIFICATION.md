## 4. 最終ZIPの検証・外付け記録

`BUNDLE_MANIFEST.json`は自己を除く収録全ファイルのbytesとSHA256を保持します。検証ツールは次を確認します。

```powershell
python -B tools/verify_bundle.py --root .
```

ZIPを指定すると、CRC・エントリーの安全性・ファイルの重複・全内容hashを検査できます。`--extract-to`を併用すると、存在しない新しいフォルダへ安全確認後に展開し、展開内容を再検査します。

```powershell
python -B tools/verify_bundle.py --root . --archive C:/plm/PLM-L1-Claude-Review-2026-09-07.zip --extract-to C:/plm/check-01
```

ZIP自身のSHA256は自己参照を避けてZIP外の`.sha256`に置きます。最終ZIPを実際に展開した内容照合・起動結果も、同階層の`PLM-L1-Claude-Review-2026-09-07-VERIFICATION.json/.md`へ記録します。この文書内のテスト結果は梱包前のレビューコピーに対する結果であり、最終ZIPを変更したり、ZIP生成前にその展開検証の成功を先取りした記録ではありません。

最初のコピーでWindowsの長いパス制限が発生したため、配布ルート名を短い`L1-review`にしました。失敗した途中コピーは作業領域へ移し、元成果物は変更していません。利用者も短い場所へ展開してください。
