# 接続仕様 v0.1

## 役割と既存実装

L1の `PartialModel`、部分観測の状態符号、局所更新、SS改訂記憶、生成モデルと受理条件を変更しません。P1の `PhaseCodebook` を使う位相結合と、既存S1 v0.2の `transmit / synchronize / despread_aligned` を接続します。

L1は5役割（主体・対象・述語・肯否・仮定）と時間関係・提示順・部分観測状態を持ちます。旧P1のR1向け役割語彙とは異なります。本版はL1信号を旧P1の全意味スロットへ変換するものではなく、P1位相符号のプリミティブと部分相関の原理をL1向けに接続したものです。旧P1 v0.2の役割別干渉部分空間除去は使用しません。R1固有の隔離・applied・target_clauseを新たに実装したとは主張しません。

変更しない継承ファイル93件は [PREVIOUS.json](verification/PREVIOUS.json) に出所とハッシュを残しています。

## 送受信

1. 8,192成分のL1複素意味信号 `x` に、P1の公開単位位相符号 `b` を成分ごとに掛ける：`z = x * b`。
2. `z` を2,048成分ずつの4フレームに分ける。
3. 各成分を4チップへ拡散し、1フレーム4か所の公開パイロットとガードを加える。
4. 受信信号・観測マスク・公開ゲインから、フレームごとに整数遅延、一定周波数差、位相を推定。
5. 逆拡散して4フレームを結合し、`conj(b)` を掛けてL1座標へ戻す。
6. 観測座標だけを使ってL1意味候補を照合し、受理できればSS記憶と生成へ渡す。

4フレームのすべてが同期受理されなければ、文書全体を保留します。フレームの大まかな切り出し境界、順番、ID、公開ゲインは外部契約です。無限の連続波形から文書開始位置を探す実装ではありません。

各フレームのP1コードブックseedは、固定プロファイル、外部固定message ID、フレーム番号から導出します。別フレームの混入・入替えをパイロット不整合として検出できる構成ですが、暗号認証ではありません。受信パケット自身が指定したIDを無条件に信頼せず、呼出し側の期待IDと比較します。

|フレーム数|4|8|
|ペイロードチップ|32,768|65,536|

|ガードチップ|128|256|

これは正規化した離散モデルです。RF電力・帯域の実測ではなく、JSON、浮動小数点表現、ヘッダー転送、PC上の実行時間も上表には含めません。非拡散反復対照は同じチップ数・パイロット数・総エネルギーです。直結対照はチャネルなしの機能基準であり、同じ送信予算の比較ではありません。

S1の探索は±4 Hz、受理は±2 Hz、整数遅延は±8チップです。フレームごとに同期をやり直します。チャネルの位相は直列経過時間に合わせますが、連続的な追尾ループではありません。

## L1用部分相関

通信上の未観測座標と、意味上の `unobserved` 状態は別です。通信マスクを正解意味のマスクに置き換えません。

観測集合を `M`、L1の固定候補位相符号を `c_j` とすると、候補の振幅は次で計算します。

```text
s_j = Re(sum(conj(c_j[M]) * sqrt(3) * x_received[M])) / |M|
```

最低4,096座標の観測を必要とし、既存L1の最小スコア0.65、上位差0.25、存在支持0.65を維持します。出来事数、提示順、状態、候補数、候補集合を順に回復し、選ばなかった候補の強い支持も拒否します。これらは確率ではなく設計された判定規則です。

回復候補を再符号化して観測座標上の相対残差を検査し、0.20を超える場合は保留します。通過したときだけ、未観測座標を候補の符号で補います。**実際に観測した値は一切取り替えません。** 最後に既存L1の全座標回復と残差0.20の条件にも通す二段階検査です。

この補完は仮説による再構成であり、欠けた元サンプルを真値として復元できた証明ではありません。任意の偏ったマスク・未知干渉に対する保証や、旧P1の適応閾値の移植ではありません。

## 教師受信・記憶更新・冷間生成

`learn_received` の呼出しは、その受信文書を外部教師として受け入れる明示的な操作です。受信信号から全意味状態を回復し、外部指定された2対象の値だけを取り出して、既存のSS誤差更新へ渡します。正解表を別引数で渡しません。同期失敗・意味回復失敗・未確定な教師では更新しません。

更新はコピーした記憶上で段階的に行い、すべて通った場合だけ新記憶を返します。成功した教師の誤った内容まで見抜けるわけではありません。有効な形式の誤教師を学習する試験も含みます。推定した自分の答えを外部教師とみなす自動経路はありません。

評価の欠測照会は、2対象をともに意味上の `unobserved` とした別信号です。元教師の受信パケット、回答値、確認済みsessionを渡しません。保存・再読込したSS記憶と、その照会の受信信号から補完します。SS係数を消すと生成できなくなることを試験します。

保持するのは指定2項目であり、全文書すべてをSS長期記憶から再生する課題ではありません。それ以外の文脈は照会信号から受け取ります。各主試行のSS記憶は独立で、後続の大量学習による忘却試験は本版に重ねていません。

## 分離と限界

同期受理、意味回復、教師更新、SS補完、生成成功、独立パーサとの一致、再読解を分けて記録します。同期成功は意味の正しさ・送信者認証・世界の真偽を意味しません。

8,000.1 Hzと0.1 Hzの折り返しは、この1サンプル/チップモデルでは識別できません。受入範囲外の信号をすべて拒否できるとは主張せず、該当例を別の限界条件に記録します。

意味の符号基底、部分相関、記憶のSS係数更新を使用しますが、通常の制御・辞書・状態検査も残ります。記憶演算の全過程を物理時間上の発振・同期回路に置き換えたものではありません。
