# データと評価の範囲

生成元は `evaluation/cases.py`。既存語彙・文法の組合せを固定乱数で作り、過去の5,275場面指紋と重ならない32場面を採用した。指紋は事象IDや時間関係を除き事象内容をソートした粗い表現であり、単なる表現順の違いも既出とみなす保守的な除外である。

開発用は焦点4＋後続4、評価用は焦点12＋後続12。全て2事象。主体・対象・行為・肯否・仮定・時間関係を6種類の対象ペアで覆い、各照会で2項目を未観測にする。scene、scope、known、query、教師文章は `data/CORPUS.json` に収録した。

「未見」は場面の組合せについてであり、新語・新文法の獲得を意味しない。最終評価時にも焦点場面の教師は明示的に与える。教師を全く見ていない意味を自力で知る試験ではない。言語モデル本体は再学習していない。

外部教師文章を既存モデルで読み、意味信号をP1/S1でチップ化し、25%チップ観測・遅延・一定周波数差・位相差・雑音の既存条件を通す。教師24と照会12の計36受信を一度ずつ作り、同一の受信結果を4方式×3記憶seedで共有する。36×12個の独立通信試行を行ったとは数えない。

後続教師の1件が既存同期判定で保留された場合も除外や再抽選を行わず、学習を保留した事実を記録する。したがって実際の学習件数は結果の `INDEX.json` と `TEACHERS.json` を参照する。

主評価は4方式×3seed×12焦点照会=144文書照会、2出力要求ずつ。内部故障は7条件×3seed×4照会=84、係数ゼロ対照は3seed×4=12。計240文書照会・480出力要求を予定する。生成保留は誤文書と区別し、成功分だけの精度を主成績として扱わない。

語順保持・主体焦点と、順序反転・先頭の対象焦点の2形を実際に生成し、限定文法の独立パーサーで事象・関係・順序・焦点を検査する。モデル自身の再読も併用するが、それだけを正解判定にしない。

評価コードと正解データは推論用の最小隔離ディレクトリにコピーしない。コード依存関係と別プロセスの生成結果は `verification` の記録で確認できる。
