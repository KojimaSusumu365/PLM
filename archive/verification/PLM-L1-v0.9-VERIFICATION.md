## 限界

Linuxでの実機実行は未実施。Windows内の別ディレクトリ・別プロセスと1 ULPの制御試験を、Linux互換性の実証とは呼ばない。厳密な配布ハッシュと、再学習に対する機能許容差を分離する実装を提供した。

旧v0.8の全低次元・数値雑音評価は今回再実行していない。v0.9の標準言語回帰と、新合成依存課題450条件を2回評価した。SSの一般的な性能優位性や、全SS学習、P1/S1接続は未達。

## 再実行

展開した `PLM-L1-v0.9` で、未使用の出力先を指定する。

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:PYTHONIOENCODING='utf-8'
python -B verify_release.py --mode functional --legacy --out ../v09-verification
```

外部Linuxで新しい機能比較だけを試す場合は `--legacy` を外す。旧版ZIPの歴史的な厳密指紋・環境依存の検査は変更していないため、旧版検証は別に扱う。
