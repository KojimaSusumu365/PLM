# 0. この資料の位置づけ

本資料は、PLM（Phase Language Machine）という、SLM/LLMとは異なる計算原理を持つ言語モデルを検討する過程で生まれた仮説を整理したものである。

中心となる着想は、以下である。

> **脳は、各部位が異なる処理を行いながら、なぜ一つの系として協調できるのか。**

この問いに対し、SS（Spread Spectrum: スペクトラム拡散）、PN符号、部分相関、相関積分、多数決、三値 \{-1, 0, +1\}、Concept形成を一つの計算原理として捉えられないか、という方向から議論した。

重要な注意点として、本資料では以下を厳密に区別する。

- **既知の事実・工学的原理**
- **神経科学で知られている関連概念**
- **PLM設計のための仮説・比喩・モデル**
- **まだ検証されていない推測**

特に「脳が実際にPN符号を使っている」「1.58-bit LLMの本質が90°回転である」などは、現時点で確立された事実ではない。本資料では、それらを**PLMを考えるための計算モデル**として扱う。

# 2. SS（スペクトラム拡散）との類似

## 2.1 DS-SSの基本

DS-SSでは、データ \(d(t)\) をPN系列 \(c(t)\) によって拡散する。

\[
s(t)=d(t)c(t)
\]

受信側では、同じPN系列を使って相関を取る。

\[
y=\int r(t)c(t)\,dt
\]

目的信号は相関しているため積み上がる。

一方、非相関信号やノイズは正負が打ち消し合う。

概念的には、

```text
目的信号     + + + + + + + +  → 積分 → 大
非相関信号   + - - + - + + -  → 積分 → 小
```

となる。

重要なのは、SSでは**一瞬の信号が弱くても、正しい符号で長く相関積分すれば復調できる**という点である。

---

## 2.2 脳への仮説的対応

工学的SSと脳を次のように対応させる。

| SS通信 | 仮想的な脳モデル |
|---|---|
| 情報データ | 知覚・記憶・判断・運動情報 |
| PN符号 | 神経集団固有の時空間パターン |
| Chip | 短い時間窓・発火単位 |
| 拡散 | 多数ニューロンへの分散表現 |
| 相関器 | シナプス入力＋時間積分 |
| Processing Gain | 相関した入力の集積利得 |
| 非相関信号 | 関係のない神経情報 |
| 復調 | 意味・知覚・判断の選択 |

ただし、これは**仮説的な対応関係**であり、脳が文字通りDS-SSを実装しているという主張ではない。

# 3. 完全直交ではなく「部分相関」

初期の単純仮説は、

> 脳領域ごとに別のPN符号を持つ

というものだった。

しかし、完全に異なる符号なら、各領域が協調しにくい。

そこで次の考えに進んだ。

> **全体としては非相関に近いが、一部分だけ似ている符号を持つ。**

たとえば、

```text
A : + - + + - - + - | + + - + - + - -
B : - + - + + - - + | + + - + - + - -
                         ↑
                    局所的に似ている
```

全体相関は低くても、

\[
R_{AB}\approx0
\]

特定の区間では、

\[
R_{AB}^{(\mathrm{local})}>0
\]

となる。

これにより、

- 普段は干渉しない
- 必要なときだけ協調する

という関係を作れる。

# 4. 「90°回転」と三値 \{-1, 0, +1\}

高次元ベクトルの角度として考える。

2つのベクトル \(x,c\) の相関を、

\[
\rho=
\frac{x\cdot c}{\|x\|\|c\|}
=
\cos\theta
\]

とする。

理想化すると、

\[
0^\circ \rightarrow +1
\]

\[
90^\circ \rightarrow 0
\]

\[
180^\circ \rightarrow -1
\]

と対応できる。

意味としては、

| 角度 | 三値 | 解釈 |
|---|---:|---|
| 0° | +1 | 支持・強化・同方向 |
| 90° | 0 | 無関係・棄権・不参加 |
| 180° | -1 | 反対・抑制・逆方向 |

ここで特に重要なのは **0** である。

0は、

> 「私はこの判断には参加しない」

と解釈できる。

この意味で、三値は単なる量子化ではなく、

\[
\boxed{
支持 / 無関係 / 反対
}
\]

という分散合意の最小表現になり得る。

# 5. 1.58-bit LLMとの関係

BitNet b1.58などで使われる代表的な三値重みは、

\[
w\in\{-1,0,+1\}
\]

である。

3状態の情報量は、

\[
\log_2 3 \approx 1.585
\]

bitである。

ただし、

> 1.58-bit LLMの本質が「0°/90°/180°の幾何学」にある

というのは確立された説明ではない。

PLMではむしろ逆に、

> **三値を位相・相関・参加状態として明示的に定義する**

ことを検討する。

すなわち、

\[
+1 = 支持
\]

\[
0 = 非参加
\]

\[
-1 = 反対
\]

を、Concept形成・推論・合意形成に直接使う。

# 6. ニューロン多数決としての解釈

各ニューロン、あるいは各小集団が、

\[
q_i\in\{-1,0,+1\}
\]

の投票を行うと考える。

集団では、

\[
S=\sum_i w_iq_i
\]

と積分する。

そして、

\[
S>\theta
\]

なら次段へ伝播する。

ここで、

- \(q_i\): 支持/無関係/反対
- \(w_i\): 信頼度・結合強度・相関強度
- \(\theta\): 発火/採択閾値

と考える。

この場合、脳全体の協調は、

> 中央司令塔が全領域を統括する

のではなく、

> **局所的な重み付き多数決が多段で起きる結果、全体として整合した状態が残る**

と解釈できる。

# 9. 脳の省電力性との接続

CMOS ICの動的電力は概念的に、

\[
P_{\mathrm{dynamic}}
\approx
\alpha CV^2f
\]

で表される。

ここで、

- \(C\): 配線/ゲート容量
- \(V\): 電圧
- \(f\): 周波数
- \(\alpha\): スイッチング活動率

である。

通常のデジタルICでは、

- クロック
- 大規模配線
- メモリアクセス
- データ移動
- MAC演算

で大きな電力を使う。

一方、脳は、

- イベント駆動的
- 疎な発火
- 局所的な記憶と演算
- 分散表現
- 閾値判定
- 低活動率

という特徴を持つ。

PLMにおいて0を、

> **計算不参加**

として物理的にもスキップできれば、

\[
90^\circ
\rightarrow
0
\rightarrow
No Operation
\]

となる。

この場合、0は情報表現であると同時に、省電力状態になる。

# 10. Dropoutとの接続

Dropoutは学習時に一部のユニットを0にする。

通常の目的は、

- co-adaptationの抑制
- 過学習の防止
- 冗長な分散表現の形成

である。

今回のモデルでは、

\[
0 = 投票不参加
\]

と解釈できる。

つまりDropoutを、

> **特定のニューロンだけに依存しない分散多数決を訓練する操作**

と見ることができる。

SS的には、

> 一部のchip/信号が欠損しても相関ピークが残る

という冗長性に近い。

ただし、DropoutとSSは同じアルゴリズムではなく、構造上の類似である。

# 11. PLMのConcept層

ここからPLM本体に入る。

PLMでは、SLM/LLMのようにToken列だけを中心に扱うのではなく、**Concept層**を設ける。

Concept層では、

> 様々な言い方から、表現固有の差を引き、より限定されたConceptへ変換する

ことを考えている。

例：

- 「犬が吠えている」
- 「ワンちゃんが鳴いている」
- 「イヌが声を出している」
- “dog is barking”

これらは表層が異なる。

しかし共通して、

- DOG
- VOCALIZE/BARK

というConceptを持つ。

# 12. 「引き算」と多数決

初期的には、

\[
X_i=C+E_i
\]

と考える。

- \(C\): 共通Concept
- \(E_i\): 言い回し固有成分

しかしここで重要な問題がある。

単純に、

\[
X_1-X_2
\]

とすると、

\[
(C+E_1)-(C+E_2)
=
E_1-E_2
\]

となり、欲しい共通Concept \(C\) が消える。

したがって、PLMの「引き算」は通常のベクトル減算ではない。

より正確には、

\[
\boxed{
共通成分を推定
\rightarrow
非共通残差を除去
}
\]

である。

つまりConcept層は、

\[
\boxed{
Common Mode Detection
+
Residual Suppression
}
\]

と定義する方がよい可能性がある。

---

# 13. Concept形成を投票として見る

Concept候補ごとに特徴投票を行う。

\[
q_{ik}
\in
\{-1,0,+1\}
\]

- +1: Concept \(C_k\) を支持
- 0: 無関係
- -1: Concept \(C_k\) に矛盾

Conceptスコアを、

\[
S(C_k)
=
\sum_i w_iq_{ik}
\]

とする。

例えば、

| Candidate | Vote |
|---|---:|
| 生物 | +5 |
| 動物 | +5 |
| 犬 | +4 |
| 猫 | -2 |
| 乗り物 | -5 |

しかし単純多数決では「生物」「動物」のような広い概念が勝ちやすい。

そこでPLMでは、

> **支持を失わない範囲で、より限定されたConceptへ降りる**

必要がある。

---

# 14. 「引き算＝限定化」という解釈

例：

\[
生物
\]

から、

- 植物
- 菌類
- 微生物

などの可能性を除き、

\[
動物
\]

へ限定する。

次に、

- 猫
- 馬
- 人
- 鳥

などを除き、

\[
犬
\]

へ限定する。

すなわち、

\[
\boxed{
Concept形成
=
支持されている意味空間から、
矛盾する可能性を引き続ける操作
}
\]

と捉える。

これは「多数決」と矛盾しない。

多数決で、

- 支持される領域
- 無関係な領域
- 反対される領域

を決めた後、

**反対票のある領域を意味空間から削る**

と考えればよい。

# 18. 手話的・空間的PLM内部文法

例えば、

「犬が人を噛む」

を単なるToken列ではなく、

```text
DOG  ----agent----\
                   > BITE
HUMAN --patient---/
```

のようなグラフとして保持する。

あるいは位相を役割に使う。

概念的に、

\[
DOG@Phase_A
\]

\[
HUMAN@Phase_B
\]

\[
BITE:(A\rightarrow B)
\]

とする。

この場合、

「人が犬を噛む」

では、

\[
BITE:(B\rightarrow A)
\]

となり、Conceptを変えずに関係だけ変更できる。

## 21.1 SSは本質か、単なる比喩か

SSは、

- 符号が既知
- タイミング同期が必要
- 相関器が必要

という明確な通信方式である。

脳やPLMに当てはめる場合、

- Concept Codeを誰が作るのか
- 未知ConceptのCodeはどう作るのか
- Code同期をどう行うのか
- 学習でCodeが変わったら過去表現とどう整合するのか

を明確にしなければならない。

---

## 21.2 多数決は多数派バイアスを持つ

多数票が常に正しいとは限らない。

- 稀だが重要な特徴
- minority evidence
- exception
- anomaly

が消える危険がある。

したがって、

\[
S=\sum q_i
\]

だけでは不十分であり、

- 信頼度
- 独立性
- 希少性
- contradiction

を加味した重みが必要になる可能性がある。

---

## 21.3 相関した票は独立票ではない

100個のユニットが全て同じ誤った情報源に依存している場合、

100票ではなく、

\[
1種類の誤情報\times100
\]

である。

これは、

- ニューロン集団
- 人間社会
- AI ensemble

全てで問題になる。

---

## 21.4 Conceptを限定しすぎる危険

引き算を強くしすぎると、

- 文脈
- ニュアンス
- 比喩
- 感情
- 曖昧性
- 多義性

まで消してしまう。

人間言語では「曖昧なまま保持する」ことも重要である。

したがってConcept層は、

> 必ず1つに確定する

のではなく、

\[
\{C_1:p_1,C_2:p_2,\ldots\}
\]

のように複数候補を残す必要がある場合もある。

## 21.5 90°＝0 は綺麗すぎる可能性

\[
0^\circ,+1
\]

\[
90^\circ,0
\]

\[
180^\circ,-1
\]

は数学的に美しい。

# 24. 本仮説の核心

現時点で最も重要な仮説を一文で表すと、

> **PLMは、言語表現をToken列として直接予測するのではなく、複数表現に含まれる部分相関を検出し、三値投票と残差除去によってConceptを復調し、そのConcept間関係を空間的・位相的内部文法で保持した後、Surface Grammarによって自然言語へ戻す。**

となる。

\rightarrow
Residual Subtraction
\rightarrow
Concept
\rightarrow

\rightarrow
Language
}
\]

である。
