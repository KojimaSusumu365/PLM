# SS型短文書生成の接続仕様

## 目的と範囲

既存v0.9のSS型読解・語彙生成・時間表現記憶を、新しい二／三事象の数値信号へ接続する。追加の自然文コーパスによる学習や、SS-active v0.3の教師選択・補助記憶を言語へ移植する実験ではない。接続は「文章→SS意味信号→文章」である。

出力は限定語彙・限定文法の二文または三文。入力で述べた出来事を、同じ順または逆の提示順で、主体先行／対象先行の語順を指定して書き直す。何を書くかを自律的に決める文書計画、要約、自由長文、未知語、照応、省略は対象外。

## 学習する対応と手設計の部分

一事象の語彙、役割、肯否、仮定、語順、助詞などの配置はv0.9のSS連想記憶から読み出す。時間接続表現も学習済みのSS記憶へ照会し、生成器に「beforeならその後」という表を置かない。学習は既存の432文章・意味対、時間216二事象対、初期語彙から再実行する。SS型特徴選択器を使用する。

三事象への反復、事象数、局所ID、句点と接続prefixでの分割、関係スキーマ、端点IDの付け替え、信号の結合、復元閾値は手設計である。三事象の構造を学習から発見したとは言わない。生成は学習済みのSS対応で語彙・語順・マーカーを選び、その部品を通常のPythonで連結する。すべてをSS演算で行う実装ではない。

## 意味契約

事象は `event:0`、`event:1`、必要なら `event:2` の局所的な発生IDを持つ。同じ内容の事象が複数回現れても同一の発生としてまとめない。文書間の同一事象判定ではない。

各事象にはsubject／object／predicate／polarity／modalityの五項目を保持する。presentationは提示順。全ての事象対に、明示的なbeforeの向きまたはunknownを保持する。

三文では、接続prefixは**直前に書かれた事象との関係**を表す。隣接していない第一・第三の関係はunknownであり、推移的にbeforeへ変更しない。「その後、その後」から第一と第三の順序を推論することは別の課題として残す。否定・仮定文の出来事が現実に生起したとも推論しない。

指定する出力順はpreserve／reverseだけ。反転は隣接関係を保つため、明示した二本の関係をどちらも書ける。任意の並べ替えでは元の非隣接関係を落とし得るので許可しない。提示順で非隣接の事象対に明示関係を付けた意味入力は、書けない情報を黙って落とさず拒否する。

## 一つのSS信号

基本次元は8192、複素128-bit。二事象でも三事象でも同じ次元。単一の信号へ、事象数、発生IDに結合した各意味項目、事象対と方向を結合した時間関係、提示順を重畳する。

```text
x = (count_code
     + Σevent (presence(event) + Σrole ID(event) * ROLE(role) * VALUE(value))
     + Σpair PAIR(pair) * KIND(kind) * SOURCE(source) * TARGET(target)
     + ORDER(presentation)) / sqrt(3)
```

unknownではsource／targetの項は用いない。記号値から単位複素位相符号への変換は固定されたSHAKE由来の符号生成であり、新たに学習した符号ではない。相関で候補を復元し、全信号の再構成との相対残差で整合を確認する。

条件はv0.9のまま、最大相関0.65以上、次点との差0.25以上、事象存在0.65以上、全再構成残差0.20以下。相関は確率ではない。未知の入力を保留することと、復元した意味が外界で正しいことは別である。

## 生成器へ渡すもの

パケットは次の六項目だけ。

```text
schema, model_fingerprint, dimension, real, imag, eligible_for_inference
```

原文、出来事配列、意味JSON、事象数、提示順のヒントを含めない。事象数と提示順は信号から復元する。モデルには既知の候補語彙と学習済み係数が必要だが、入力文書の意味や原文を埋め込むことはない。ユーザーの出力順や文内語順の指定は生成方針であり、世界の意味を上書きする指定ではない。

別プロセスの隔離試験では、reader、trainer、SS特徴選択器、評価器、教師データを除き、モデルと数値パケットのみで二文・三文を生成する。事象数に相当するgoals引数すら渡さず、信号から数を読み取れることを検査する。

パケット指紋はモデルの厳密な同一性を検査するためのもので、暗号署名や通信路の改ざん防止ではない。別の有効な意味信号へ数値を書き換えれば、その意味を出力し得る。制御された局所編集の試験はその性質も示す。

## 拒否と比較

読解の途中で一文が失敗した場合も、部分的な完成文やパケットを成功として返さず、文書全体を保留する。生成時の意味復元や一事象・一接続の出力が失敗した場合も同様。

診断用に、発生IDの項目結合を除く、時間の方向を消す、学習済みの読取／生成／語彙係数を実際にゼロにする条件を比較する。正答数だけでなく、誤答、生成保留、読解失敗による生成未実行を分ける。条件の詳細は `evaluation/PROTOCOL.json`。

数値雑音・半分消去の試験は、現時点ではP1の部分観測やS1のチップ列・パイロット同期へ接続したものではない。符号、学習済み係数、通常メタデータ、固定サイズのSS照会キャッシュはそれぞれ費用として扱う。
