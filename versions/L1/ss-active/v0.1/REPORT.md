# PLM-L1-SS-active-v0.1 実施報告

共有誤差更新とSS照合に基づく、追加教師の能動選択。

実施日：2026-09-08。研究用の独立実験。`eligible_for_inference=false`。

実装と評価を完了しました。高負荷・正解固定の人工課題では、SS平均相関の曖昧さに基づく教師選択が無作為より回復を改善しました。一方、正解変更の発見・未登録誤受理・他の記憶への干渉には限界が残ります。これは文章生成の完成版ではなく、そのための教師取得部品の実証です。

## 1. 目的と位置付け

前版 `PLM-L1-SS-multicode-v0.1` では、独立した符号を複数用意しても、照合結果の厳しい一致を受理条件にするだけでは、正しく読める項目まで保留する問題が残りました。一方、4ブロックに共通の平均誤差を用いる `concat512` は、512次元の一つの連想記憶として更新する構成と代数的に等価です。

本版では、この共有誤差型の記憶を維持したまま、照合の曖昧さ・符号間不一致を「どの項目について追加教師を求めるか」に使用します。受理を厳しくするのではなく、外部から得た正解で記憶そのものを訂正したときの利益・副作用を測ります。

v0.13の追加教師取得という設計上の考え方を受け継ぎますが、v0.13の依存関係マスク探索器へそのまま統合したものではありません。今回は既習の完全な人工キーを再度尋ねる実験です。部分観測、未知の依存規則、二事象の意味構造、自然文の読解・生成、P1/S1通信的復調の統合は対象外です。

## 2. 実装した仕組み

### 2.1 SS表現と共有誤差更新

文脈は `f0`～`f3` の4項目、それぞれ値 `"0"`～`"7"`。ラベルは `"0"`～`"3"`。各項目・値を固定された複素位相ベクトルで表し、4項目の要素積で文脈符号 `b_k(x)` を作ります。符号ブロックは4本、各128次元です。

```text
s[k,y] = Re(sum_d conj(H[k,y,d]) * b[k,d])) / 128
mean_score[y] = mean_k s[k,y]
error[y] = 1[y = external_teacher_label] - mean_score[y]
H[k,y,d] <- H[k,y,d] + 0.5 * error[y] * b[k,d]
```

全ブロックに同じ `error` を使います。4本を独立に正解へ合わせる更新ではありません。学習済み係数は `4×4×128 = 2,048` 個のcomplex128、32,768バイトで固定です。係数に正解表を併設すること、教師の再生バッファ、自己予測からの擬似教師化は行いません。

前版の `__init__.py`、`algebra.py`、`model.py`、`learning.py` をバイト不変で引き継ぎ、ハッシュを検査します。512次元平坦モデルとの更新一致も単体試験に含めます。

### 2.2 比較する教師選択

|方式|優先順位|同点時|SS照合の論理的対象数／選択1回|
|---|---|---|---|
|無作為 `random`|`hash(seed, context_id)` の固定順|文脈ID|選ばれた1件の診断値のみ|
|平均曖昧さ `ambiguity`|平均相関の上位2ラベルの差が小さい順|同じハッシュ順|残候補すべて|
|符号不一致 `disagreement`|各ブロックの最有力候補のGini不一致が大きい順|同じハッシュ順|残候補すべて|

Gini不一致は、ラベルごとの投票割合 `p_y` に対する `1 - sum_y p_y^2`。各ブロックの上位2候補の差が `1e-12` 以下なら、そのブロックは4ラベルへ均等票を投じます。範囲は0～0.75です。相関・投票割合・Giniを、校正済みの正解確率や独立した意味の証拠とは解釈しません。不一致方式に平均曖昧さの二次順位は加えていません。

外部教師1件による更新ごとに選択をやり直します。取得済み項目は候補から取り除き、取得期間中に同じ項目を二度選びません。

### 2.3 教師情報との境界

`select()` の入力はSSモデル、ラベルなし候補、方式・乱数用シード・取得番号のみです。候補の各行には `id` と `context` 以外を許しません。IDは文脈だけから求めたハッシュです。教師ラベル・変化した項目・実際の誤りは渡しません。

`Session.ask()` で選択結果と現在状態の指紋を含む要求を作り、`Session.answer()` で同じ現状態に対する選択を再検証してから、対応する外部教師の回答1件を共有誤差学習器へ渡します。更新前の状態は保存され、更新後は新しい状態を返します。

要求の改変、古い要求の再使用、未知ラベル、余分な正解フィールド、`source=model_prediction` の回答を拒否します。ただし `source=external_teacher` は申告であって、人間の本人認証や教師の正しさの保証ではありません。今回の人工実験は正しい外部教師を前提とします。

候補・取得済みID・履歴ハッシュは通常の制御用メタデータです。これらをすべてSS信号へ変えたものではありません。学習・選択・評価の区分を保つため、評価結果には正解と全履歴を残しますが、それらは保存SSモデルや教師なし選択器には含めません。

## 3. 固定した評価条件

|項目|条件|
|---|---|
|負荷|群の大きさg＝64、128|
|基礎学習|互いに重ならないA・B・C、各g項目をA→B→Cの順に各4周、計12g教師|
|取得候補|Aの半分＋Bの半分、計g項目。候補の構成は評価側でラベル均衡化|
|直接再教示しない旧記憶|残り半分のA・B、計g項目|
|追加教師予算|0、4、16、32件|
|固定世界|全ラベルを基礎学習時のまま維持|
|変化世界|基礎学習後、候補内16項目のラベルを変更。変化通知は渡さない|
|後続学習|各予算時点の状態を別に分岐し、新しいD群g項目を2周学習|
|未登録照会|基礎・追加・後続のいずれの教師にも含まれない128キー|
|本評価|4データシード×2負荷×2符号シード×2世界×2取得シード×3方式＝192取得系列|

各データ・負荷・符号の基礎学習器を共有します。世界・方式・取得シードによって基礎学習をやり直しません。後続D学習の結果は次の取得へ戻さず、取得予算ごとの独立した耐忘却試験とします。Dの教師列は全方式・全予算で共通です。

基礎学習16本の18,432教師、取得系列の6,144教師、後続学習分岐の147,456教師、合計172,032教師提示が本評価1回の実行量です。これは1本の生涯学習列の長さではなく、全分岐を合わせた実験上の提示数です。別の開発データで12取得系列・11,904提示を先に実施し、その後にソース・試験・データ・条件を固定して本評価を2回実行しました。

一定の負荷・世界・方式では16系列ですが、基礎状態は8種類のデータ×符号組です。2取得シードは同じ基礎状態を共有します。数千の反復照会を独立の文章や学習課題とは数えず、対応条件間の差と、取得シードを平均した8基礎状態での勝敗を記述します。有意差・母集団への一般化は主張しません。シード間で語彙や一部のキーが重なる場合もあります。

## 4. 評価指標

暫定候補は平均相関の最大ラベル（上位差が `1e-12` 以下なら未確定）。受理は平均相関0.5以上の候補が唯一であり、暫定候補が確定している場合です。全方式・世界・予算で同一規則を使用し、追加の符号一致ゲートや評価後の閾値調整は行いません。

- 暫定正解・暫定誤り・暫定未確定：SS記憶の取り出し自体の状態。
- 受理正解・誤受理・保留：固定した受理規則を通した結果。
- 新規回復と元の正解の喪失：基礎学習後に間違っていた項目が正しくなった数と、その逆を別集計。
- 後続学習後の回復喪失：追加教師で回復した項目が、Dの学習後に再び不正解・保留になった数。
- 直接訂正の再発：選ばれた項目が教師直前には暫定誤り、直後には暫定正解だった集合について、その後の誤りを追跡。
- 未登録誤受理：未教示キーに対して既知ラベルを受理した数。

旧記憶全体A+B、候補全体、選択済み・未選択候補、直接再教示しない旧記憶、変更された項目、C、Dを分けて記録します。これらは一部重複する集合であり、すべてを足し合わせません。また選択済み集合自体が方式によって変わるため、効果の方式比較は同じA+B・候補全体等を中心に行います。

## 5. 本評価の結果

### 5.1 高負荷・固定世界：回復は改善したが、不一致方式が最良ではなかった

g＝128、32件の追加教師、16系列の集計です。旧記憶A+Bは各256件、合計4,096照会。未登録は各128件、合計2,048照会です。表の「正解」は受理正解であり、保留を正解に数えていません。

|方式・予算|測定時点|暫定正解／4096|受理正解／4096|旧記憶の誤受理|旧記憶の保留|未登録誤受理／2048|
|---|---|---:|---:|---:|---:|---:|
|追加教師なし|D学習前|3994|3440|22|634|240|
|無作為32件|D学習前|4003|3527|18|551|250|
|平均曖昧さ32件|D学習前|4046|3702|14|380|258|
|符号不一致32件|D学習前|4029|3599|13|484|267|
|追加教師なし|D学習後|3848|2978|48|1070|316|
|無作為32件|D学習後|3862|3077|46|973|318|
|平均曖昧さ32件|D学習後|3942|3198|32|866|332|
|符号不一致32件|D学習後|3913|3149|39|908|324|

同じ教師32件で、D学習後の受理正解は無作為3,077件に対し、平均曖昧さ3,198件（+121件、+2.95ポイント）、符号不一致3,149件（+72件、+1.76ポイント）でした。平均曖昧さは対応する16系列すべてで無作為を上回り、2取得シード平均の8基礎状態でも8勝0敗。符号不一致は16系列で13勝2引き分け1敗、8基礎状態で7勝1敗です。

ただし符号不一致と平均曖昧さの直接比較では、D学習後の受理正解は符号不一致が49件少なく、8基礎状態で1勝7敗でした。したがって「複数符号の不一致を使えば最良」とは結論しません。今回の試験で有効だった主役は、共有誤差型記憶への教師追加であり、選択指標では平均相関の曖昧さがより有力でした。

### 5.2 教師予算を増やしたとき

同じ高負荷・固定世界の受理正解数。各欄は「D学習前 → D学習後」、分母はいずれも4,096です。

|追加教師／系列|無作為|平均曖昧さ|符号不一致|
|---|---:|---:|---:|
|0|3440 → 2978|3440 → 2978|3440 → 2978|
|4|3453 → 2996|3502 → 3018|3471 → 3009|
|16|3480 → 3040|3634 → 3088|3543 → 3066|
|32|3527 → 3077|3702 → 3198|3599 → 3149|

平均曖昧さ16件では、無作為32件をD学習前に107件、後に11件上回りました。今回の固定条件では教師件数を節約できる可能性を示しますが、最小必要件数の推定や一般的な半減効果の証明ではありません。

低負荷g＝64の固定世界では、基礎状態ですでに暫定正解2,048/2,048でした。32件取得・D学習後の暫定正解は全方式2,044/2,048、受理正解は無作為1,985、平均曖昧さ1,992、符号不一致1,992です。ここでは主として支持の補強と保留の減少であり、存在しない暫定誤りの訂正効果を主張しません。

### 5.3 正解が予告なく変わる条件には盲点が残る

各系列で16項目のラベルを変更し、32件取得後にDを学習した結果です。変更項目の合計は各方式256件。旧記憶全体の分母はg＝64で2,048、g＝128で4,096です。

|負荷|方式|旧記憶の受理正解|旧記憶の誤受理|旧記憶の保留|変更項目を教師に選んだ数／256|変更項目の暫定正解／256|
|---|---|---:|---:|---:|---:|---:|
|64|無作為|1778|127|143|142|97|
|64|平均曖昧さ|1802|124|122|134|106|
|64|符号不一致|1780|135|133|128|87|
|128|無作為|2903|196|997|78|46|
|128|平均曖昧さ|3002|202|892|54|40|
|128|符号不一致|2970|208|918|51|40|

高負荷では能動方式の旧記憶全体の受理正解は増えますが、誤受理も無作為196件から202／208件へ増えました。変更項目の発見数は無作為78件に対し54／51件で少なく、D学習後の変更項目の暫定正解も46件に対し40／40件でした。

これは、外界の正解が変わってもSS内部では古い答えに自信が残り、曖昧さや符号不一致だけでは優先的に尋ねられないことと整合します。変更通知を渡していない2世界で初回の要求が同一になることを96組すべてで確認しました。少なくとも初回の選択に「真の誤り」を直接混入させていません。

本実験では変化の事前告知を与えず、教師は常に現在の正解を返します。誤った教師が継続して流入する条件、変化検知器の性能、人間の学習との同等性は未検証です。

### 5.4 直接訂正の効率と再発

高負荷、各方式16系列×32件＝512件の教師取得についての集計です。「直後訂正」は教師直前の暫定誤りが直後に正解になった件数。「D後再発」はその集合のうち最終D学習後に再び暫定誤りとなった件数です。

|世界|方式|教師直前に暫定誤り／512|直後訂正|D後再発／直後訂正|
|---|---|---:|---:|---:|
|固定|無作為|9|9|0/9|
|固定|平均曖昧さ|52|52|0/52|
|固定|符号不一致|38|38|0/38|
|変更|無作為|86|62|16/62|
|変更|平均曖昧さ|96|96|14/96|
|変更|符号不一致|80|78|11/78|

固定世界では、誤りを含む教師の取得効率は無作為1.76%に対し平均曖昧さ10.16%、符号不一致7.42%。ただし残りの正しい項目への教師も支持を補強し得るため、これ以外をすべて無駄とは数えません。

変更世界では教師1件で訂正しきれない例や、訂正後に再発する例が残ります。低負荷の変更世界でも再発は無作為26/107、平均曖昧さ24/120、符号不一致30/106でした。本版は同一項目を取得中に再選択しないため、再発を検知して教師をもう一度求める機構はまだありません。

### 5.5 副作用：未登録誤受理と、尋ねていない記憶の弱化

高負荷・固定世界では未登録誤受理は、32件取得・D学習後に無作為318/2,048（15.53%）、平均曖昧さ332/2,048（16.21%）、符号不一致324/2,048（15.82%）でした。追加教師なしの316/2,048を下回っていません。今回の追加教師選択を未登録誤受理対策の完成と見なすことはできません。

さらに、直接再教示しない旧記憶2,048照会の受理正解は以下のとおりです。

|方式|32件取得直後|D学習後|
|---|---:|---:|
|無作為|1734|1491|
|平均曖昧さ|1714|1478|
|符号不一致|1724|1480|

全体の改善の裏で、平均曖昧さ方式は無作為よりこの集合の受理正解が20件／13件少なくなりました。D学習後のC群でも受理正解は無作為2,001に対し平均曖昧さ1,986、符号不一致1,997（各2,048中）です。Cの暫定正解は全方式2,048ですが、受理に必要な支持が弱くなっています。

高負荷・固定世界のA+B全体で、追加教師32件の前後を分解すると、暫定正解の新規回復／元の正解の喪失は、無作為21/12、平均曖昧さ62/10、符号不一致46/11です。受理正解の新規回復／喪失は125/38、326/64、221/62。回復だけを数えず、SS重畳を更新する際の干渉を同時に見続ける必要があります。

### 5.6 計算・保存の費用

g＝128の同じ保存基礎モデルから、3方式をそれぞれ3回、他の評価実行が終わった後に1プロセスで測定しました。固定符号キャッシュを温めた状態での中央値です。

|方式|32件の要求選択|32件の回答検証＋更新|照会1文脈、128件バッチ|
|---|---:|---:|---:|
|無作為|0.084秒|0.166秒|0.109ms|
|平均曖昧さ|0.462秒|0.554秒|0.112ms|
|符号不一致|0.462秒|0.549秒|0.105ms|

論理的な選択時の照合対象数は、教師32件で無作為32文脈、能動方式は候補64件なら1,552、候補128件なら3,600文脈です。`answer()` は要求の妥当性確認のため選択を再計算するため、これは実際の総照合回数やFLOPsではありません。回答時間にはその再検証も含みます。候補リストの複製・ハッシュ計算等もあり、無作為方式が制御処理を一切しないわけではありません。

学習係数は全方式32,768バイト、固定原子符号の温キャッシュ262,144バイト。32件取得後の候補・取得済みID等を含む圧縮表記JSON状態は無作為14,248、平均曖昧さ14,251、符号不一致14,254バイトでした（保存時の字下げや外側の指紋を除く）。Pythonオブジェクト、配列生成の一時領域、全プロセスRSS、消費電力は測定していません。教師件数・係数量は同じですが、総メモリや総計算量が同じとは主張しません。

## 7. 結論と次の段階

「SS記憶の現在の状態から、訂正に有用そうな教師を自分で選び、外部の正解を共有誤差更新へ接続する」最小実証は実装できました。人工的な既習キーの高負荷・固定世界では、同じ教師予算の無作為取得より回復が改善し、後続学習後にも差が残りました。

ただし、今回の結果は次の3点を区別すべきです。

1. SS平均相関の曖昧さによる選択は有力でしたが、複数符号の不一致による選択がそれを上回ったわけではありません。
2. 外界の正解が変わり、内部が古い答えで一致している場合には、能動選択に盲点が残りました。
3. 教師を増やすだけで、未登録誤受理・他項目への干渉・訂正後の再発が解消するわけではありません。

次の一段は「探索を残した追加教師選択と、訂正の保持」であると考えます。曖昧な項目の優先取得に加えて、一定の無作為な確認枠を確保し、符号が一致したまま正解が変わった項目にも到達できるかを比較します。また、1回きりの再教示という制約を明示的に変え、再発した項目をいつ再確認するかを評価します。混合比や再確認の規則は新しい開発データで決め、本版の評価結果へ後付けして最適化しないことが重要です。

この次段階でも、教師件数とSS係数の容量をそろえ、未登録誤受理・直接尋ねていない記憶・変化項目の発見率を必須指標とします。否定教師や登録有無を追加する場合は、新しい教師情報を使用したことを独立条件として扱います。

その後は、抽象キーだけの改良を続けるのではなく、二事象の読解・意味保持生成へ戻し、「どの主体・行為・対象・時間関係を聞き直すと、意味を混同せずに書き直せるか」を確かめる段階が必要です。本版はその教師取得部品であり、文章生成やP1/S1を新たに完成させたものではありません。
