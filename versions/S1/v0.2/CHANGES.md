# S1 v0.1 → v0.2

旧S1 v0.1全330ファイルを無変更でvendorへ保存。P1/R1/C2の実装と結果、過去の失敗条件を維持します。

新パッケージplm_s1_v02に、4か所のパイロット配置、±4 Hzの粗探索と微調整、±2 Hzの受入範囲、遅延・周波数候補差、補正後のブロック整合性検査を追加。曖昧な推定は保留します。8480チップ、パイロット256チップ、送信エネルギー57344を維持します。

新wire形式v2を導入し、旧形式を暗黙変換しません。回復比較に加え、範囲内・境界・範囲外・雑音・不整合入力を評価します。配置だけを旧型へ戻す対照も含みます。

離散サンプリングのFs周期の曖昧性や有効パイロットによる偽装は解消していません。推論開放、RF実機、独立意味評価は実施しません。
