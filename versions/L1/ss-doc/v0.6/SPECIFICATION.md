# v0.6 仕様と境界

## 1. 目的と変更範囲

本版は、後続学習でSS記憶の支持が弱まる状況を作り、限られた回数の再確認をどの項目に使うかを学習する最小実証です。v0.5の内容記憶、数値意味信号、局所訂正、受理条件、言語生成モデルは変更しません。独立したSS選択器を追加します。

内容を覚えるSSと、確認の価値を覚えるSSは別の係数です。選択器の高い評価値は、内容の正しさを証明しません。選ばれていない箇所も含め、生成時には既存の受理条件を適用します。

## 2. SS選択器

### 観測できる特徴

入力は18個の固定した数値特徴です。候補自身の平均照合スコア、上位差、4符号の投票割合、符号間スコアのばらつき、支持の有無、共有側のスコアと投票、記憶領域の不一致、同文書のもう一方の対象のスコア・差・投票・支持、弱支持と相手支持の組合せ、両方弱支持、保護領域の有無、登録量、3事象フラグ、バイアスです。

尺度とクリップ範囲は固定し、評価結果から調整しません。これらは手設計した特徴です。文章の正解、未来の保持結果、教師の答え、出来事ID、根ハッシュ、対象名を学習特徴には入れません。支持とは現在のSS照合判定であって、実際に正しいと知っていることではありません。

### 表現と学習

4チャネルそれぞれに256次元の複素位相符号 `b_kf` を生成します。特徴値を `f` とし、加算型のSS特徴信号を作ります。

`x_k = sum_f(feature_f * b_kf) / sqrt(18)`

確認価値の予測は、学習済みSS係数 `W_k` との相関です。

`prediction = mean_k(Re(sum(conj(x_k) * W_k)) / 256)`

外部教材の価値を `reward` とすると、共有誤差 `error = reward - prediction` を用い、正規化した加算更新を行います。

`W_k += 0.03 * error * x_k / mean_k(sum(abs(x_k)^2) / 256)`

学習用576件を固定順のシャッフルで12周、計6,912更新します。学習済み係数は16,384 byte、再生成する特徴符号基底は294,912 byteです。符号基底はRAM費用であり、全体を永続ファイルへ保存しているわけではありません。

これは手設計特徴に対して線形な、小さなSS価値近似器です。同種の関数は通常の線形モデルでも表現でき、通常の線形回帰等への優位性は本実験では比較していません。「SSで選択価値を学習・保持できる」という実装範囲と、他方式より優れるという主張を区別します。評価値は正答確率でも、生成許可でもありません。

### 教師値

学習用の各候補について、確認なしの枝と1回確認した枝へ、同じ64件の新規背景を各2回学習させます。選択した文書に対する次の効用の差を教師値とします。

`utility = (2 * correct_document + correct_target_count - 4 * wrong_document) / 4`

2項目とも正しく復元できれば文書正解、2項目とも確定しているのに少なくとも片方が違えば誤った文書、欠測が残れば保留です。片方を正しく保持したことにも点を与えます。他文書への副作用は教材に記録しますが、報酬へ含めていません。したがって長期・全体最適な価値関数ではありません。

学習用では全正解を用いて対比較を構築します。評価中にはこの対比較を行わず、選択器も再学習しません。選択した項目の外部回答だけで内容SSを更新します。

## 3. 照会と確認の流れ

`Workset` は1～64文書の数値入力と外部スコープ指定を保持します。本実証の入力は、各文書の2訂正項目がともに `unobserved`、それ以外が既知であるものに限定します。既知の古い値・矛盾入力の混合はv0.5の別機能として維持しますが、v0.6の選択比較には混ぜません。

可変対象、出来事ID、非対象の意味、提示順から既存の根ハッシュを求め、`hash(root,target,revision)` でSS照合します。可変対象の正解はアドレスに入れません。全スコープの初期登録は通常のメタデータ管理で、未学習の対象は改訂0です。選択に使う焦点対象は初期確認済みでなければなりません。

候補集合は12文書×2項目の24候補です。各確認の後でSS照合をやり直します。その選択ラウンドですでに確認した `[id,target]` は外し、同じ対象を二度選びません。履歴は外部の制御情報であり、教師値や正解の辞書ではありません。

比較方針は次の3つです。

|方針|選択基準|
|---|---|
|rule|現行の必要確認優先度を使用。領域間不一致95、支持のない欠測70、任意確認0。同点は対象名・文書ID順|
|random|残候補をseed・ステップ・ID・対象の固定ハッシュで擬似無作為順にする|
|ss_learned|SS価値予測の高い候補を選び、同点だけ対象名・文書ID順|

`rule`はv0.5の優先度を複数文書へ広げ、任意保持確認を追加した対照です。v0.5と全く同じ実行条件を再現した名称ではありません。IDを同点処理や無作為対照に使うことと、IDから価値を学習することも区別します。

確認回数を厳密にそろえる実験なので、すでにSS支持が十分な対象も「任意の保持確認」として選択可能にします。これは通常運用で必ず6回質問すべきという推奨ではありません。「確認しない」を学ぶ停止方策は未実装です。

質問はスコープ・対象・基準改訂・入力ハッシュ・記憶フィンガープリントに結び付けます。古い質問、不正対象、未知の値、変更済み入力を拒否します。正式な外部回答は既存のv0.5確認処理を通して内容SSだけを更新します。確認済み数値パケットを将来の照会へ使い回さず、元の両方欠測入力を維持します。

ハッシュは信頼されたローカル処理内の整合性検査であり、暗号署名や教師の真偽検証ではありません。正しい形式の誤教師を学習することはあり得ます。任意の悪意あるPythonオブジェクト編集、並行書込み、電源断時の複数ファイル一括トランザクションは扱いません。

## 4. 後続学習の固定プロトコル

[PROTOCOL.json](evaluation/PROTOCOL.json) と [FREEZE.json](evaluation/FREEZE.json) に条件を固定しています。

各焦点文書にA1→B1→A2→B2→A3の5回確認を与えます。背景学習を0/64/256件まで進めた3つの状態から、それぞれ独立に比較を始めます。各背景出来事は2回連続で確認し、2回目は同じ値です。

各状態のコピーについて、3方針とも異なる対象をちょうど6回確認します。確認後、まず教師回答履歴なしのSS照合で即時の意味保持を測ります。ここでは文章生成は行いません。続いて新規背景64件を各2回学習させ、内容SSを保存・再読込して、元の両方欠測入力から文章を生成します。

対応する無確認対照にも同じ後続背景を学習させます。無確認対照は即時・遅延の意味保持だけを測定し、文章出力要求の分母へ含めません。初期・背景の教師情報は対応する比較間で同じです。追加確認は6回答ずつ同数ですが、回答の情報量や人間の回答の難しさまで等価としたわけではありません。

2評価分割 × 3内容符号seed × 2内容記憶構成 × 3背景段階 × 3選択方針 = 108条件です。各条件12文書、遅延照会は1,296件、各2表現で2,592出力要求。追加確認は計648件です。独立な焦点場面は24件で、1,296の独立自然文ではありません。学習用24場面と評価用24場面は別です。

内容SSの2構成は `versioned_shared` と `versioned_pair`。それぞれ係数94,208 byteです。後者の保護対象は外部が事前指定し、背景は共有領域だけを更新します。SS選択器を使う方式だけには追加係数と符号基底の費用があります。係数容量や計算費用が全方式で完全に同一という比較ではありません。

## 5. 生成判定と監査

内容の受理条件は、4符号の平均スコア0.5以上、閾値を越える候補が1つ、上位差0.15以上、3/4以上の一致、登録済みアドレス、共有・保護領域の強い不一致がないことです。今回この条件を変更していません。価値予測が高くても、内容の支持が弱ければ生成を保留します。

即時段階では対象2つのSS復元を評価側の正解と照合します。遅延段階では実際の数値意味パケットの補完と、この対象照合が一致することも検査します。文章は提示順保持と逆順・焦点変更の2種類を要求し、独立した限定文法パーサと既存読解器への再入力で採点します。非対象セルの不変性も別に記録します。

独立パーサは生成モデルの重みを使いませんが、人間による盲検評価や任意の日本語を解釈する評価器ではありません。保留した要求も分母に含め、成功例だけを評価対象にしません。

## 6. 本版で実施しないこと

質問文・文法の学習、任意文書長、新語の獲得、同一出来事の自動同定、世界の真偽検証、選択器のオンライン報酬学習、未来の全干渉の予測、P1/S1の物理的同期復調は実施していません。SS以外の通常の制御・辞書・数値処理も使用しています。

残った失敗を見て生成閾値や教材を調整せず、今回の固定条件での結果と限界を報告します。
