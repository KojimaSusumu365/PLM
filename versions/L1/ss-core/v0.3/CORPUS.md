# 評価資料と教師の境界

## 既存の学習済み言語モデル

v0.2同梱の `model/` をバイト変更なしで使用する。語彙・役割・肯否・仮定・語順・助詞等・時間接続を担う10個の学習済みSSメモリは、それぞれ131,072byteの数値係数、合計1,310,720byte。各メモリは元のバンク構成を保つ。今回はこれらを新しい文章コーパスで再学習していない。

## 新しいSS遷移記憶の教師

文内の目標焦点2通り×肯否2通り×仮定2通り＝8条件について、既存モデルから抽象的な語彙照会／記号出力の列を得る。68遷移をSS結合重畳係数へ転写する。文書提示順2通り×出力順指定2通り＝4条件の12遷移は、明示された順序仕様から教師を作る。

この新しい教師は人物名・動詞を含む完成文や意味全体をキーとして保存する方式ではない。人物・動詞は実行時に既存の語彙SS記憶から取り出す。ただし、正しい抽象手順を教師として与えているので、「読み方・書き方を無教師で発見した」とは呼ばない。

## 開発・本評価データ

`data/WAVE03_CORPUS.json` に開発4文書、本評価24文書を固定。作成手順は `evaluation/cases03.py` に含む。別seedを用い、両splitの意味全体の重複を禁止する。本評価は過去の全学習／全評価データとの非重複を保証していない。この版の主眼は実行経路の移行であり、新規一般化の立証ではない。

全て既知の6人物・4動詞・肯否・仮定・2事象・時間関係3種類の限定語彙／文法の範囲。各事象内で主体と対象は異なる。2事象の肯否は互いに反対、仮定／断定も互いに反対となるように組む。従って、2事象の状態の全組合せを網羅した実験ではない。人物・動詞の組合せは固定seedで抽出する。

本評価24文書の時間関係は未指定／事象0が先／事象1が先が各8文書。入力の主語／目的語焦点を交替させ、各文書から次の2出力を要求する。

1. 順序保持、2文とも主語焦点。
2. 逆順、第1文は目的語焦点、第2文は主語焦点。

3方式各48要求、計144要求。学習した意味を採点器から生成器へ渡さず、入力文章を読んで得た信号から生成する。正解意味は評価器だけが参照する。

## 別枠の補助試験

本評価の先頭2文書を使い、9条件の故障注入を各2例、部分状態3種類を各2例、外部P1/S1接続を2例、訂正記憶への教師登録・保存・再ロード・欠損照会からの生成を2例行う。訂正接続試験は新規記憶への登録であり、長期の連続訂正や忘却耐性を測るものではない。

外部接続と訂正登録では正解意味を外部入力・教師として使う。それを、正解を隠した文章読解評価と混同しない。別の `examples/` には、実際の文章読解から得た信号をP1/S1へ送り、新規プロセスで生成した往復例を収録する。

未知語、未知動詞、不整合な仮定、役割重複の無効入力4例も確認する。これらの少数例は、全ての未知文や誤教師を安全に拒否できる保証ではない。

## 独立採点の意味

`evaluation/oracle.py` と `event_oracle.py` は、既存のSS読解器とは別実装の限定文法パーサーである。生成文の意味、時間関係、事象順、焦点を採点する。実装の独立性はあるが、言語の仕様・語彙は共有しており、人間の独立レビューや自然コーパスでの評価とは異なる。
