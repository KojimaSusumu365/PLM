## 機械可読な証拠

- `TESTS.json`：単体試験の実出力。
- `RELEASE_VERIFY.json`：保存状態・相関・学習再生・隔離実行。
- `REFERENCE_REPLAY.json`：参照取得計画の再計算。
- `REPEATABILITY.json`：二重実行の対象とハッシュ。
- `PRESERVATION.json`、`PREVIOUS_BASELINE.json`：旧成果物保全。
- `CLI.json`、`examples/EXPECTED.json`：CLI実行と更新例。
- `AUDIT.json`：報告表の照合と補足ストレスの独立再生。
- `ENVIRONMENT.json`：実測環境。

配布ファイル全体は最終的な `RELEASE_MANIFEST.json` で検査する。配布前の `RELEASE_VERIFY.json` にある `manifest_files_checked=null` は、内容検証時にはまだ最終マニフェストを作っていなかったことを意味する。ZIPを実際に新規展開した後の検証は、ZIPと同じ場所に置く `PLM-L1-SS-active-v0.3-VERIFICATION.md` に別途記録する。

Windows 11、Python 3.12.14、NumPy 2.3.5で検証。Linux実機は未検証。`eligible_for_inference=false`。観察専用なので、実際の追加教師選択・訂正保持・文章生成の改善を確認した意味ではない。
