# 開発試行と本評価

凍結前に54単体テスト、単項課題の30取得過程の通し試験、主客・二世界・範囲外課題の30取得過程の重点試験を実行した。重点試験はD512・一符号・一取得seedと記号的対照であり、本評価の480過程には加算しない。

開発の重点試験では、隠れた依存のある世界で能動選択が全件正答へ達するのに4教師を必要とした。一方、最終評価分割では1教師で達した。この差を隠さず、1教師という結果を一般的な必要教師数の保証としない。

開発記録は `development/critical-cases.json` と `development/EVALUATION.json` に保存した。最終ソース・データ・固定条件の凍結後に取得順位や閾値を変更せず、本評価を二回実行した。

追加教師は人工データに対する評価側の教師役から、一要求につき一ラベルを取得した。人間からの実際の回答や外部データ収集を行った実績ではない。
