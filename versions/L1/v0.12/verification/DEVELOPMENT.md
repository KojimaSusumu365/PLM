# 開発試行と最終評価の区別

開発用の新分割70モデルを実行した後、最終ソースと本評価データを凍結した。開発中に、まだ評価器・プロトコルを作成していない段階での旧版テスト参照エラー、テスト起動先の取り違え、係数比較関数への旧版未対応引数を是正した。

これらは本評価前の実装・検証配線の修正で、最終評価結果を見てデータ、学習重み、選択、閾値を調整したものではない。97テスト通過後の凍結で295モデルを二回実行した。本評価開始後の凍結対象ソース変更はない。

`development/` は凍結前の70モデルの試行結果であり、本評価の合否や本評価295モデルへ加算しない。その後、二世界のモデル・予測一致を集計する監査項目を評価器に追加したため、開発試行の検査数は本評価と異なる。実行時の判定算法・閾値は同じ。開発・本評価とも同じ有限構造化課題族を使い、新しい自然文ドメインではない。
