# 数値仕様

## 符号と比較予算

v0.1のSHAKE256決定的単位複素Phase符号を再利用します。出来事キー・役割キー・記号符号の成分ごとの積を各結合の符号とし、全結合を加算します。加算後の信号は単位振幅ではありません。文書scope、出来事、役割、個体IDを維持します。

主体/対象と他の役割を半分ずつの座標へ分ける2領域分割方式も比較しました。各結合をsqrt(2)倍して、結合あたりのエネルギーを元のDに保ちます。状態情報は削除しません。

比較実験ではさらに、各方式の実際の重畳信号を `gain = sqrt(D * 結合数 / ||信号||²)` で正規化し、送信エネルギーを厳密に一致させます。gainは送信側が信号ノルムだけから計算する単一スカラーで、すべての受信方式に等しく与えます。受信側はチャネル通過後にgainで割り戻します。したがって正規化に伴う雑音の拡大縮小もそのまま評価します。

次元D、入力frame、役割数、候補数、候補語彙、公開カタログ、マスク/雑音seedは方式間で共通です。全方式へカタログを利用可能にしますが、旧方式と分割方式は使用しません。v0.1復号器への追加判定・正解情報注入はありません。既知失敗の回帰診断だけはv0.1当時の未正規化信号を厳密に再現します。

## 干渉除去

観測成分集合Mだけを取り出します。公開カタログ内の「あり得る出来事アドレス × 述語/状態候補」の符号を列に並べた行列Bを作ります。実際の割当て、正しい状態、存在フラグは使いません。合成実験では通常8アドレス（うち4 decoy）×11候補=88列です。

SVDでBの列空間の正規直交基底Qを求めます。受信信号yと各候補符号aの双方に同じ除去を適用します。

```text
r = y - Q(Qᴴy)
t_c = a_c - Q(Qᴴa_c)
e_c = ||t_c||²
score_c = Re(t_cᴴr) / e_c
```

符号に投影を施さず信号だけを除去すると自己成分が減衰するため、双方を投影して残った符号エネルギーで割ります。

述語・状態そのものを照会する場合は、その照会アドレスの照会役割をBから外します。真の値だけを外すのではなく、当該役割の全候補を外し、照会対象を消し込まないようにします。subject/object/target_clauseは干渉候補の役割に含めません。

これは観測マスク上の複素相関と干渉部分空間除去です。通常の実数Pearson部分相関係数や、Conceptの意味距離を実証したものではありません。

## 観測に応じた判定

```text
n = 観測成分数
dof = n - rank(B)
power = ||r||² / dof
z = NormalQuantile(1 - alpha / 候補数)
amplitude_threshold = max(0.40, z * sqrt(power / (2 e_best)))
gap_threshold = max(0.10,
  1.5 * sqrt(power/2 * ||t_best/e_best - t_runner/e_runner||²))
```

runnerは正の2位候補です。2位が負または単一候補ならスコア0・符号0のnullを比較先にします。`alpha=0.01` は候補数を考慮するための近似設定です。残留干渉を複素等方ガウスと見なす近似であり、実際の確率校正・誤受理率1%保証ではありません。powerは対象信号も含むため、純粋な雑音分散の不偏推定ではありません。

観測128成分未満、除去後の自由度128未満、候補の残存エネルギーが観測数の半分未満なら保留します。広すぎる干渉カタログも保留を増やします。相関の高い二候補、欠落真値、未観測、存在しない出来事を、明示的な負例・境界試験で確認します。

スコアは確率でも正規化cosineでもなく、負値や1超もあり得る振幅推定です。全候補の首位/差の判定は丸め前に行い、JSONの診断値は表示・再現用に丸めます。

## 評価の解釈

未知評価は16符号seed×4独立チャネルseedの交差、各条件512正例・1024負例です。負例は出来事なしと真値が候補にない場合。12条件・5方式の総照会数と、別のパイロット/状態照会数を分離して報告します。

主目標は2048次元・4出来事・28結合・候補96・観測25%・複素雑音RMS0.15・成分別位相揺らぎ標準偏差0.1 radで回復95%以上、負例誤受理2%以下。全観測・無雑音は全回復/誤受理0を目標とします。それ以外は診断的ストレス試験です。

同一符号seedやチャネルseedを共有する照会を独立な大量標本とは見なしません。seed別の実測変動を報告し、無誤りの試験結果を母集団リスク0と解釈しません。符号・マスクの乱数は新規ですが、人工frameの生成規則と評価者は共通であり、未知の自然文や独立意味評価へ一般化する保証はありません。

公開語彙外の述語を混ぜる診断もありますが、未知の任意干渉を自動検出・完全除去できるわけではありません。保留を受理へ強制するfallbackはありません。
