# Changes in PLM-C0 v0.3

- Expanded the benchmark from 36 to 288 deterministic cases.
- Added explicit dev/test splits and 12 adversarial semantic templates.
- Added ASCII token boundaries and longest-match overlap suppression.
- Added configurable feature ablations.
- Added schema validation, Macro-F1, coverage/selective accuracy, calibration, and Brier score.
- Added cluster bootstrap intervals and a paired baseline-delta interval.
- Added per-label, per-tag, and aggregated failure reporting.
- Preserved all ten original v0.1 behavior checks.
