# v0.3：訂正対応のSS記憶保持と再照会

## 到達目標と境界

v0.2は、その場の観測信号を外部情報で訂正する。v0.3は外部で確認された対応をSS係数へ学習し、後から新しく受け取った未確定観測に照合して生成する。保存した訂正済みパケットや完成文の再表示ではない。

学習するのは「特定の出来事の、特定の項目について、以前確認された値」である。文法・未知語・曖昧さの発見・同一出来事の自動認識は学習しない。既存SS言語コアと部分観測コアはバイト不変で継承し、言語係数を変更しない。SS-activeの共有誤差・保護記憶という考え方を、この文書課題向けに別実装したもので、旧SS-active全体をそのまま統合・等価再現したものではない。P1/S1も未接続。

## 再利用の識別

外部指定のepisode ID、局所事象と役割からなるtarget、対象以外の観測内容から、SHA-256キーを作る。

```text
key = hash(episode ID, target, event count, presentation, all non-target cells)
```

targetの値・状態・候補集合はキーに含めない。従って同じ文書の「二候補」「未観測」「読み取り不能」を照合できる。一方、他の項目や提示順が変わると別キーになる。文内語順が違っても読解後の同じ観測なら一致するが、事象順反転に伴うIDの再割当てや別表現の同一性を自動認識しない。今回の出力順反転は、照合後の生成方針である。

同じ文章でもepisode IDが違えば別の出来事として扱う。IDを取り違えた外部システムまで訂正することはできない。IDとハッシュは意味の正しさや本人性の認証ではない。exactな文書文脈でのエピソード記憶であり、語彙や文法の一般化ではない。

## 学習するSS係数

4本の独立した複素位相符号を使う。意味ラベルは役割と値の組で、主体6・対象6・行為4・肯否2・仮定2・時間3の計23候補。符号自体は固定であり、学習されるのは重畳係数である。

pair方式：

```text
Z[k,y] = context_code[k,key] * label_code[k,y]
score[k,y] = Re(vdot(Z[k,y], H[k])) / D
error[y] = onehot(external_confirmation)[y] - mean_k(score[k,y])
H[k] += sum_y(error[y] * Z[k,y])
```

bank方式はラベルごとに係数を分け、context_codeだけを使う。同じ4本の平均誤差で各ラベルの係数を更新する。利得は1。以前の正解を辞書から読み出して差し引くのではなく、SS読み出しと新しい外部ラベルとの差分で更新する。改訂後の完全保持・旧値の完全消去を数学的に保証しない。

外部教師の検証と係数学習はlearning.pyに分離する。v0.2のパケットハッシュ・局所更新・事後条件を通過したknownの確認だけを学習する。対象以外の文脈は全てknownが必要。普通の矛盾情報を自動的に教師とせず、resolve/reviseによる明示的な確認が必要となる。評価では同じ検証済み教師列を全方式へ渡す。推論中に予測を教師として自己学習しない。

## 比較方式

| 方式 | 共有記憶 | 保護記憶 | 学習係数合計bytes |
|---|---|---|---:|
| none | なし | なし | 0 |
| shared736 | pair：4×736 | なし | 47104 |
| shared1472 | pair：4×1472 | なし | 94208 |
| split_pair | pair：4×736 | pair：4×736 | 94208 |
| split_bank | pair：4×736 | bank：4×23×32 | 94208 |

共有記憶は訂正教師と背景教師を全て学習する。保護記憶はprotect=trueと外部で指定された訂正教師だけを学習し、背景教師を学習しない。保護対象の選択を学習で発見したのではない。共有と保護は異なる符号を使う。

等容量なのは学習係数だけで、固定ラベル基底・文脈キャッシュ・通常メタデータ・時間まで同じではない。文脈キャッシュは各記憶32件までで、内容は固定キー符号のみ。正解や読み出しスコアはキャッシュしない。

## SS照合と受理

問い合わせ役割の候補全体で平均相関を求める。平均0.5以上が一つだけ、次点（負の場合は0）との差0.15以上、4符号のうち3符号以上が同じ最大候補を支持する場合に十分なSS支持とする。現在の二候補だけに狭めて無理に答えを出さない。相関は確率ではない。

普通の台帳には、学習したキーのハッシュ集合と全体の更新回数だけを保持する。教師値、完成文、訂正済みパケット、入力意味配列を保存しない。ラベル一覧は全モデル共通の候補語彙であり、キーから正解を引く表ではない。

台帳にないキーは、SSが強く支持しても再利用しない。従って未登録の最終誤適用ゼロをSS単体の未知検出能力と呼ばない。評価では、台帳で止める前の生SS誤支持も別に数える。

保護記憶に登録があれば、その支持を使う。ただし共有記憶が十分な支持で別の値を示せば保留する。共有が弱いだけなら保護側を使える。保護側が弱い場合は共有だけへ自動フォールバックしない。保護に登録がなければ共有を使う。これは設計した受理方針であり、最適な方針を学習したものではない。

## 生成時の動作

- ambiguous：保持した値が現在の候補内にある場合だけ補完する。
- unobserved／unreadable：同じキーへの十分な登録済み支持がある場合だけ補完する。
- conflict：記憶では解決せず再確認する。
- known：現在の明示値を記憶で上書きしない。十分な確定支持が別の値なら再確認する。弱い／確定できない記憶は新しい明示値を上書きする根拠にしない。

補完はv0.2の局所数値差分で行う。対象外の意味は保持する。補完した数値パケットだけを既存生成器へ渡す。生成器は原文や現在の教師を受け取らない。episode IDはSS記憶の照合に必要な外部識別子であり、通常メタデータを全廃したものではない。

## 保存と再起動

記憶はstate.jsonとweights.npzの二ファイル。係数・候補語彙・符号設定・ラベルなし登録ハッシュ・更新回数の指紋を検査する。キャッシュや正解辞書を復元する必要はない。記憶を保存して再読込した後、新しい未確定パケットから同じ対応を取り出せるかを評価する。

## できないこと

情報なしに外界の変化を検知できない。以前の確認が古くなっても、同じ観測だけを渡せば古い値を支持し得る。誤った外部確認の真偽も判定できない。強いSS支持や台帳登録は世界の正解を保証しない。自由な長文、未知語、照応、省略、複数項目の依存推論、同一出来事の自動対応付け、教師選択の閉ループ最適化は未実装。`eligible_for_inference=false`。
