# PLM-L1 v0.12 技術仕様

## 1. 目的

v0.11のhybrid3は部分特徴から有用な回答を増やした一方、複数の意味が成立する入力にも確定を出した。完全入力での相関余裕と、部分入力の情報が十分であることは同じではない。

今回は基礎の位相平均・特徴選択・calibrationを変更せず、回答を拒否するだけの追加ゲートを実装する。部分入力の正解教師を追加して手動の安全ルールを学習させる方式ではない。基礎モデルにない回答を新しく作る方式でもない。

## 2. 基礎モデル

同梱の `plm_l1_v011/` は前版とbytes一致。選択した特徴集合Mごとに、各特徴の位相符号を積で結合し、その1〜3次項を加算するhybrid3、または全特徴の一つの積productを使う。

`W_y = mean(phi(x_i) | y_i=y)` のクラス別記憶を持ち、`Re(conj(W_y) dot phi(q))/D`でスコアを求める。閾値は旧版の完全入力calibrationのままで、欠落条件に合わせて再調整しない。相関差は確率ではない。

今回のゲートはadditiveにもAPI上適用できるが、本評価はhybrid3とproductに限定する。加算型の能力を今回あらためて測ったとはしない。

## 3. 学習済みの裏付け記憶

各保持候補iの選択特徴M_iについて、訓練例の射影された完全キー `k=x|M_i` とラベルyを使う。同一 `(k,y)` の反復は学習時に重複除去し、同じキーへ異なる教師があれば両ラベルに残す。

```text
b_i(k) = product_{f in M_i} a_witness(f, k_f)
H_i,y = sum_{unique training keys k paired with y} b_i(k)
r_i,y(k) = Re[conj(H_i,y) dot b_i(k)] / D_i
```

基礎モデルとはseedの名前空間を分けた単位複素位相符号を使う。期待上は既知のキー／ラベルが1、無関係なキーが0へ相関するが、有限次元では干渉する。固定閾値0.5以上を裏付けのヒットとし、目的ラベルだけがヒットすることを要求する。目標ラベルなし・競合ラベルのヒット・両方ともゲートを止める。

SS実行時にはクラス別H配列だけを保存し、完全キーの対応表や訓練例そのものを保存しない。クラス別キー件数・ラベル・選択マスク・学習語彙はメタデータとして残る。SSで未知を絶対に検出できる保証はない。

記号的対照は同じ重複除去済みキー／ラベルの0/1表を使い、同じ制御手順で照会する。評価の正解表ではなく、訓練で見たキーだけの表である。SSと全RAM・速度を同一予算にした比較ではない。

## 4. 補完による十分性ゲート

入力qは観測できた特徴だけを持つ辞書。欠けた特徴の値を勝手に一つへ推定して埋めない。

1. v0.11の基礎モデルが保留なら、そのまま保留。候補上限超過や不支持も解除しない。
2. 基礎モデルの確定ラベルyを固定する。
3. 各保持候補の選択特徴について、qにない特徴を、**訓練語彙に含まれる値の直積**で列挙する。選択外の特徴は補わない。
4. 各補完キーを同じ候補の学習済みWへ照会し、全てが閾値を満たしてyを返すことを確認する。
5. 同じ補完キーについて、裏付け記憶Hでyだけがヒットすることを確認する。
6. 全候補の全補完が通った場合だけ、元の確定を維持する。

全候補を合計した補完数が256を超えれば保留。256件だけ見て成功扱いにはしない。完全文脈でも候補ごとに補完1件として裏付けを調べる。観測済みの未知語彙は基礎の在庫検査で拒否するため、この拒否をSS記憶だけの成果とは数えない。

この手順で、ANDにおいて一方が偽なら他方不明でも偽を維持できる。一方が真なら他方の補い方で結果が変わるので保留する。ただし、学習器がANDという依存を適切に獲得している範囲に限る。

## 5. 四つの比較ポリシー

| ポリシー | 処理 |
|---|---|
| baseline | 前版の回答をそのまま出す |
| observed_only | 全保持候補の選択特徴が観測済みでなければ保留 |
| consensus_only | 学習モデルの全補完一致だけを調べ、Hは調べない |
| completion | 全補完一致と学習済みHの裏付けを要求。既定方式 |

全追加ポリシーは拒否専用であり、baselineが保留した要求を確定へ変えず、確定値を別のラベルへ変更しない。したがって誤答削減だけでなく、元の正答をいくつ止めたかも報告する。全保留を性能改善とはしない。

## 6. 何を保証しないか

補完空間は真の世界の全可能性ではなく、学習されたマスクと訓練語彙で定めた有限空間である。マスク外の未知の依存関係、未登録語彙、未発見ラベル、誤教師、分布変化は残る。今回のデータには、訓練・選択・calibrationが完全に同じで未観測の真の規則だけが違う二世界を含める。同じ学習結果のまま両方の真実を言い当てられるとはしない。

裏付けの存在は「その選択キーがその教師と一緒に現れた」という記憶であり、選択特徴が本当に必要十分である証明ではない。無関係と誤って落とした特徴の検証をHが自動で回復するものでもない。

ゲートの列挙・全称一致判定・閾値・候補数・語彙管理は通常処理。SS側は基礎予測と裏付け検索の数値演算を担当する。全SS実装、脳の再現、一般的な論理推論の獲得とはしない。

## 7. 評価と費用

v0.11の19課題・追加教師前後21条件をそのまま使い、hybrid3／product×SSの2次元・2符号／記号的対照を比較。基礎指紋と全基準照会はアーカイブの前版結果へ照合する。加えてhybrid3の選択なしを単項・XOR・ANDの第一置換で測る。

新しい分割は同じ有限構造化課題12個と、未知相互作用の二世界。新分割では一特徴と二特徴の削除を別々に採点する。開発側は別seed。新しい語彙・自然言語ドメインでの一般化ではない。

部分入力の可能ラベルは評価側の完備化表から算出する。複数ラベルなら、どれか一つへ偶然合っても誤確定とする。完備化表や真の依存は訓練器・実行器へ渡さない。完全入力の四分割・追加教師との重複を検査する。

補助記憶の負荷試験は64キーの中から4／16／48キーを格納し、D128／512／2048×2符号と記号的対照を比較する。既知回復、他ラベルのヒット、未格納のヒットを別々に数える。言語全体の誤受理率ではない。Hを実際にゼロ化する対照も行う。

Hの追加費用はSS候補当たりC×D複素係数。基礎Wと同じ大きさであり、同じ総係数予算で改善したとはしない。符号帳、JSONメタデータ、照会時の分岐数と時間も別計上。推論の分岐数は語彙数と欠落特徴数で増えるため、一般の大語彙・長文へのスケーラビリティを実証したとはしない。

## 8. 保存・隔離・再現性

モデルは `base/` の旧版モデル2ファイルと、`guard.json`・`witnesses.npz` で構成。基礎指紋・H配列ハッシュ・メタデータから新指紋を作り、在庫・次元・有限値・SSに記号表が混入していないことを検査する。悪意ある送信者の認証ではない。

配布ソース・固定データ・評価器・テスト・検証器を本評価前に凍結し、全数値実行2回を比較。時刻・計時・環境は結果digestから除く。再学習の厳密指紋と、係数atol=rtol=1e-12・離散的判断の機能比較を区別する。

隔離学習には両実装のコードと明示的な訓練・選択・calibration対だけを渡す。隔離照会には保存モデル・観測特徴だけを渡し、両版のtraining.pyと全データ・評価器を取り除く。この照会は数値のみの復号ではなく、観測特徴を持つ構造化入力である。

v0.11数値復号器は無改変のまま残るが、直接呼べば新ゲートを通らない。文章系への接続、数値信号だけによる意味不足推定、P1/S1通信統合、Linux実機、量子化・疎化・スパイク/STDP、R1推論開放は範囲外。`eligible_for_inference=false`を維持する。
