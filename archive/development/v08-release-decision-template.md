# PLM-L1 v0.8：実施内容・受入判断・限界

2026-09-07。「二事象の時間関係の学習と意味保持生成」の限定実証を実装し、事前に固定した456項目、機能・旧版回帰441テスト、全数値評価2回一致を通過した配布候補である。実際のZIP展開検証結果は、ZIP外の`PLM-L1-v0.8-VERIFICATION.md/.json`へ別途記録する。これを一般言語理解・推論の完成宣言とはしない。

## 1. 今回できたこと

v0.7の二事象分離に、文章・意味対から学ぶ時間関係の読み方／書き方と、提示順から独立した時間辺を追加した。入力は明示二文、接続は「その後、」「その前に、」または接続の記述なし。前二者は相対的な時間の前後、記述なしは順序不明へ対応する。

例：

```text
入力：太郎が花子を助けた。その後、花子が健太を褒めた。
提示順を逆転した生成：花子が健太を褒めた。その前に、太郎が花子を助けた。
```

出来事の内容と「助ける方が先」という時間関係を保持し、書く順番と接続表現だけを変える。接続なしの入力からは、逆順生成でも時間関係を創作しない。「だから、」「同時に、」、代名詞を含む未対応文などは文書全体を保留する。

生成へ渡すのは一つのD次元複素数値パケットと生成要求だけで、原文・事象一覧・時間辺JSON・提示順ヒント・採点goldを別途渡さない。人向け実行例は`examples/ROUNDTRIPS.json`に分離した。

## 4. 対照と診断の読み方

- 時間学習をゼロにすると、時間読解・時間表現生成は保留する。
- 教師の前後ラベルを反転すると、その反転対応に追従する。通常の日本語に対する正答という意味ではない。
- 接続を「記号甲、」「記号乙、」へ置き換えても対応を学ぶ。
- 「その前に、」を訓練から除くと、未学習の読み方と該当方向の書き方を保留する。
- 普通の六キー対応表も関係照合を全件正しく処理できる。SS独自の精度・速度・容量の優位性は示していない。
- 時間辺のsource/targetを区別しないundirected対照は、前後を反転した信号が完全に同一になる。方向付きboundとpartitionedでは分離される。

低次元・雑音条件の全結果と失敗を`REPORT.md`および`EVALUATION.json`へ保存した。低次元・雑音試験は正解意味から直接符号化するcodec単体の診断であり、読解から通信路を通して生成する試験ではない。有限試験での誤答・誤受理の観測値から一般的な安全保証を導かない。

具体的に、四seed合計のbound復元はD128で335/864正答・529保留、D512で860/864正答・4保留、D2048/8192で864/864正答だった。この診断の受理誤答は0。別の二雑音seedではD8192・相対L2雑音比0/0.05/0.15で各432/432を復元し、0.30/0.60は各432件すべて保留した。強い雑音を除去して復元できたのではない。

undirectedでは各Dの既知時間576件すべてが辺反転で同一信号になった。時間学習ゼロは読解216・生成432件すべて保留。教師反転／無意味marker置換はそれぞれ読解216/216・生成432/432が変換後の対応に一致。「その前に、」欠落は読解144/216・生成288/432が正答で、残り72/144件は想定通り保留だった。

boundとpartitionedはD個の数値係数と期待平均成分エネルギーを揃えた比較であり、各信号の実ノルム・モデルメタデータ・候補基底・全RAM・実行時間を揃えてはいない。partitionedも位相コードを利用する。

## 6. 残る限界と次の検討

「〜する前に」の埋込み節、時刻・期間・同時性・因果、三事象以上、代名詞／省略、未知語・未知構文は未対応。IDは当該パケット内の発生IDであり、再読解では新しく割り当て、評価時に対応を明示して比較する。同一内容の二回提示を二発生として保持しても、文書をまたぐ実世界の同一事象認定にはならない。

肯否・仮定は各事象のスロットとして保持する。ただし既存の仮定文は後件のない人工的な制御形であり、否定・仮定の作用域や非生起事象の時間論理を解いていない。時間関係はこの実験の記述レベルのラベルで、出来事が現実に起こったことや原因結果を証明しない。

v0.6のバンク負荷偏り、P1数値部分観測・干渉除去、S1明示チップ列・同期、全SS学習、R1推論・Concept更新は未変更／未実装。`eligible_for_inference=false`を維持する。

次の候補は、学習した時間対応と手設計構造を分けたまま、語順と関係表現の変化に対する独立人手評価を追加すること。その後に三事象へ進むなら、可変個数ID・辺の表現、曖昧／矛盾時の保留、干渉と容量を先に仕様化する。これらは本版で未着手である。
