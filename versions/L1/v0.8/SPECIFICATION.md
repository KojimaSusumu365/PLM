# v0.8 数値・学習・事象同一性の契約

## 1. 意味グラフ

トップレベルは`events/presentation/temporal`のみ。eventsは正確に二つで、各要素は`id`とsubject/object/predicate/polarity/modality。idはevent:0/event:1の局所的な発生IDで、値の等しい出来事も別々に保持する。events配列の格納順はID順に正規化し、表示順には使わない。

presentationは二IDの順列。temporalは`{kind:unknown,source:null,target:null}`または`{kind:before,source:ID,target:他方ID}`。afterという独立関係種は持たず、逆向きのbeforeとして表す。自己辺、同時、原因、関係自体の否定や仮定は対象外。

読解時に初回提示順で局所IDを作る。その後は同じパケット内でIDと時間辺を固定し、生成要求によってpresentationだけを入れ替える。再読解は新しいIDの割当てであり、元IDを表面文から復元したとは主張しない。評価者はgoldのIDを読解器の初回提示IDへ明示的にalpha-renamingする。完全に同一内容の二発生について、外部世界での個別同一性を区別できたという主張はしない。

## 2. 一つのSS/VSA型信号

`F_i = B_i * (P + Σ_r R_r * V(value_i,r))`。

`T = time_role * kind(before) * source(ID_s) * target(ID_t)`。sourceとtargetは異なるnamespace。unknownの場合はtime_role*kind(unknown)とし、辺がないことをゼロ信号で代用しない。

`O = presentation_role * presentation_value([ID_a, ID_b])`。

標準`z = (F_0 + F_1 + T + O) / sqrt(2)`。各事象の存在と五スロットで十二成分、時間一成分、提示順一成分の計十四成分をD個のcomplex128係数に重ねる。Dは128〜16384の128倍数。固定SHAKE256位相コードは識別用で、学習した分布意味埋め込みではない。

復元はID／役割／値の結合基底との相関、三つのtime候補、二つのpresentation候補の相関を使う。存在・首位0.65以上、次位または0との差0.25以上、再構成の相対L2残差0.20以下をすべて要求する。相関振幅は確率・意味的真実・認証ではない。時間信号を欠落させた状態をunknownと見なさない。

partitionedはF0/F1/T/OをD/4幅の四区画に配置しsqrt(2)倍する。boundと総係数D・無相関近似下の平均成分エネルギー7を揃える。実際の各ベクトルのノルム、候補基底、全プロセスRAM、速度は揃えない。undirectedはsource/targetの区別を取り去り、二端点を同じnamespace・固定順で結合するため、辺の反転が完全に同じ数値信号になる診断用対照。

## 3. 文・意味対から学ぶ対応

一事象部品：v0.6と同じ432対、banked-evaluation-0、D8192、split_proof。新しい時間コーパスの216対は一事象文法の再学習には混ぜない。

時間学習の外部入力：textと上記意味グラフの対、初期lexicon。各例に操作列・語順ラベル・正解prefix境界を別途渡さない。句点二文、第二文先頭の読点までを関係markerとする分割は手設計。各文と対応する事象の内容語を初期語義IDで整列する。学習時にも新読解器／旧教師／評価oracleは不要。

読解記憶のキーはmarkerとpresentation、値はtimeの正規化JSON。生成記憶のキーはkind/source/target/presentation、値はmarker文字列。完全キーを使い、未学習の向きへ部分特徴だけで対応を一般化しない。全体文書の内容・文内語順をキーに含めないのは設計した分解規約であり、その独立性を自律発見したものではない。

各方向で六つの相異なる完全文脈を、変更しないv0.6の`fit_banked`にpartial=Falseで渡す。二記憶とも1ブロック・1バンク、D8192のうち3/4を値、1/4をキー／候補の位相確認信号に使う。新時間記憶だけの係数は合計262,144 bytes、別途ヘッダ・固定推論キャッシュ等を持つ。元の一事象部品のID3型特徴選択は残るが、新時間層でID3による特徴削減はしない。

実行モデルに具体的なキー→正解表・教師文・操作列は保存しない。候補と学習されたmarkerの在庫は公開メタデータに持つ。未知markerの保留にはこの文字列在庫を使うため、SS記憶だけで未登録表現を安全判定できたとは主張しない。

## 4. 読解・生成と情報境界

読解は句点／読点規約で分割し、一事象部品で両事象を読んだ後、時間読解記憶を照会する。得た自分の意味候補を全信号へ符号化し、両事象・辺・提示順が候補と一致して復元できる場合だけreadを返す。評価goldはこの検査に使わない。

生成は全信号を復元し、preserve/reverseで出力ID順を決め、時間と出力ID順から時間生成記憶を照会する。各IDに固定された意味を一事象信号へ再符号化し、学習済み一文生成器を使用する。生成側に原文・意味JSON・時間辺・提示順を別入力で与えない。`--goals`は出力第一／第二文の語順だけで、各出来事の時間を変更しない。

パケットschemaはplm-temporal-signal-v1。フィールドはschema/model_fingerprint/dimension/real/imag/eligible_for_inferenceのみ。数値有限性、厳密な型、次元、成分絶対値32以下、モデル一致を確認する。余分な原文・gold・時間ヒント等を拒否。旧版パケットは非互換。モデルのfingerprintは意味契約・学習メタデータ・二時間記憶のbytes・部品fingerprintから作る。重みNPZはuint8ブロック、allow_pickle=Falseで読み込む。ハッシュは署名ではない。

片側読解・生成、時間回復、提示順回復のいずれかが失敗すれば文書全体を保留する。自己整合した誤読や、別の有効な意味への改変を排除するものではない。原文からの意味正答は別実装の採点器で確認する。

## 5. データ・独立性・固定条件

train/development/evaluationそれぞれ36の事象対を用意し、ID・提示順・時間ラベルを除いて二事象の順を無視してもsplit間で重ならないようにする。九カテゴリはv0.7と同じ。時間訓練は216対、実表面文は204種類。開発・評価はそれぞれ864要求・816種類の表面文。意味グラフは各216種類。同一内容の二事象とID順の別表現により文字列の重複があることを明記する。

時間訓練には各文がsubject先行の組だけを使う。評価は四文内語順組合せ、生成は提示順二通り×文内語順四通り。既知部品を未学習の関係文書組合せへ使う試験で、未知の関係語や未知文法を獲得する試験ではない。

四評価seedで新時間記憶とcodecを変える。一事象部品は固定。標準はbound／partitioned。全条件で独立文法のイベント全スロット・相対時間・出力語順の一致を採点し、wrongとabstainを分ける。自己読解による採点だけではなく、旧系列の別実装oracleを使うが、独立した人間の自然文注釈ではない。

対照：時間学習ゼロ、教師の時間辺反転、markerの無意味記号置換、「その前に、」を学習から除く条件。欠落した向きの生成も保留を要求する。通常表の参考は同じ六つの関係キーを照会するだけで、全言語系や同一メモリの対照ではない。低次元・雑音はcodecを言語処理から切り離して測り、失敗も保存する。

ソース・データ・閾値・評価条件を固定し、未知評価の後で合わせ込まない。全数値評価の二回一致、隔離学習／生成、旧版回帰、ZIP実展開を別に記録する。限られた試験で誤受理ゼロを観測しても一般保証にしない。

## 6. 意味論上・開発上の残課題

否定・仮定の付いた事象記述にも明示関係ラベルを保持する実験仕様だが、非生起事象の時刻や条件付き時間論理を解いたわけではない。仮定形は既存の後件のない制御文で、自然な談話の全体作用域は未実装。時間関係を現実の事実、原因結果、R1の有効推論へ昇格させない。

前提の語義・役割・局所ID・分割・field設計・候補が強い制約であり、六つの小さな関係対応を学習する最小実証にとどまる。SSだけの速度・容量・一般化優位性、構造の自律獲得、全SS学習は未実証。v0.6のバンク負荷集中問題も未変更。

P1の数値観測成分マスク・干渉除去、S1の明示チップ列・同期、三事象以上、照応、永続同一性、因果推論、Concept更新は接続しない。全出力は観察専用、eligible_for_inference=false。
