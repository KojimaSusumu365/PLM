# Changes in PLM-C0 v0.2

- Added a 36-case bilingual evaluation dataset.
- Added reusable evaluation APIs and a command-line runner.
- Added Top-1, Top-5, MRR, abstention, minority-evidence, contradiction, and efficiency metrics.
- Added a positive-only lexical baseline for controlled comparison.
- Added full rankings and deterministic diagnostics to engine output.
- Preserved all ten v0.1 regression cases and added six v0.2 tests.
- Documented metric semantics, limitations, and reproducible results.
