# 検証範囲

## 固定

[FREEZE.json](../evaluation/FREEZE.json) にコード、継承実装、モデル、データ、評価条件を固定しました。結果を見て閾値・場面を差し替えていません。文書、examples、verification内の事後監査コードは固定対象外とし、最終配布時にはそれらも含む全ファイルのマニフェストを作ります。

[PRESERVATION.json](PRESERVATION.json) と [FINAL_PRESERVATION.json](FINAL_PRESERVATION.json) は原版3つの1,737ファイルとZIPの不変性、コピーした93ファイルの不変性を確認したものです。

## 試験と全評価

- [INITIAL_TESTS.json](INITIAL_TESTS.json)：新規40試験。
- [FINAL_TESTS.json](FINAL_TESTS.json)：固定後の40試験。
- [LEGACY_TESTS.json](LEGACY_TESTS.json)：原版自身の275試験。L1 116、S1 71、P1 88。入れ子の全世代試験ではありません。原版の全試験コードを接続版ZIPへ重複同梱したわけでもありません。
- [DEVELOPMENT.json](DEVELOPMENT.json)：開発4場面・88条件。主評価とは分離。
- [INDEX.json](../results/INDEX.json)：主360＋ストレス28＝388条件。
- [LOG_AUDIT.json](LOG_AUDIT.json)：全件集計、教師更新2項目、非対象不変性、生成・保留の分母、SS対照間の同一チップ、デモ数値16配列の再現。

単体試験には、未知フィールド・真の位相の混入・不正マスク・順番・IDの拒否、観測座標の厳密保持、未確定教師による自己学習の拒否、失敗時に元記憶を更新しないこと、受信学習後の保存・再読込と冷間照会、SS係数消去時の生成保留を含みます。有効な形式の誤教師は学習されることも試験します。

## 全再実行と代表再検証

[REPEATABILITY.json](REPEATABILITY.json) は全388条件を別フォルダで最初から実行した結果の照合です。時間ファイルを除く1,555ファイルが一致しました。教師受信、記憶更新、保存・再読込、照会受信、意味補完、実際の2表現生成、独立パーサと再読解を含みます。

[VERIFY.json](VERIFY.json) は別途行った次の検証です。

1. コーパスを再構築して完全一致。
2. 保存記憶388個の数値・メタデータを読み込み、結果記録のフィンガープリントと一致。
3. 各条件・方式・2/3事象数の先頭を固定選択した44条件を、教師受信から再実行。数値結果、生成・保留、保存記憶が一致。
4. 全集計・数値受入判断を再計算。
5. 全評価の再実行ファイルとの一致を照合。
6. 下記の最小ランタイムで2照会を別プロセス実行。

代表44件を全388件の3回目の実行と呼びません。デモの16配列再計算は [LOG_AUDIT.json](LOG_AUDIT.json) に別記します。

## 推論分離

[ISOLATED.json](ISOLATED.json) は、教師・コーパス・評価器・読解器・専用学習モジュールを置かない最小フォルダでの生成実行です。モデル、保存SS記憶、受信チップ、公開設定とスコープだけを渡します。固定したpartial25の2事象・3事象は、ともに生成しました。確認済みsessionはなく、SS逆拡散信号のハッシュも主評価と一致しました。

全プロジェクトモジュールの読込先が最小フォルダ内であること、教師・読解・評価モジュールをimportしなかったことを検査します。共有コードには未使用の学習補助関数やチャネルシミュレーション関数の定義も残ります。すべてのファイルから全学習・シミュレーション関数を除去した、という主張ではありません。真のチャネル値や教師をそれらへ渡す推論経路はありません。

## 配布ZIP

資料の集計・ローカルリンクを照合し、最終マニフェストを含めてZIP化します。CRC検査、実展開、全ファイルのバイト一致確認の後、展開版で40試験と上記検証を再実行します。

ZIP作成後の結果は、ZIPを書き換えず、隣接する `PLM-L1-P1-S1-v0.1-POSTZIP.json` と `PLM-L1-P1-S1-v0.1-VERIFICATION.md` に保存します。チェックサムは署名者認証ではありません。数値受入の合格は、未試験の自然文・物理チャネル・誤教師に対する保証ではありません。
