# P1 v0.2 → S1 v0.1

旧P1 v0.2全260ファイルを無変更でvendorに保存しました。旧P1/R1/C2の実装、過去の評価結果、推論無効の扱いは変更していません。

S1側に、明示的な複素チップ列、長さ4の平衡符号による拡散/逆拡散、前後パイロットとガード、整数遅延/一定小CFO/位相の推定、新wire契約、実CLIを追加しました。時間・エネルギー予算を揃えた直接参照と非拡散反復、同期なし、oracle参照も比較します。

S1のSS実装済みフラグは、人工離散ベースバンドの最小実証に限定します。RF実機・独立意味評価・分数遅延・マルチパス・認証・推論開放は実施していません。

数値評価は独立な計算workerで試行単位に並列化します。乱数seedと出力順序を固定し、worker数や実行順序によって正解/パラメータを選択しません。元のP1の演算器そのものは変更しません。
