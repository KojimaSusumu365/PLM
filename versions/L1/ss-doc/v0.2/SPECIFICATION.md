# PLM-L1-SS-doc v0.2：未確定意味と局所訂正の仕様

## 今回の目的

二／三事象のSS短文書生成へ、未確定項目の保持、対象の確認、外部追加情報による局所訂正を接続する。その場の文書状態の更新であり、言語モデルの係数更新や、次回へ残る訂正学習ではない。SS-activeの補助記憶は統合しない。

既存v0.1の `ss_document/` と `plm_l1_v09/` はバイト不変で継承する。保存された学習済み言語モデルを使い、新たな教師対による再学習はしない。旧432一事象対・216二事象対と初期語彙を再現用資料として同梱する。

## 観測状態

文書は二／三事象の固定スキーマを持つ。対象アドレスは `event:1/subject` のような局所事象IDと意味役割、または `time/event:0,event:1` のような事象対である。各項目は状態と候補集合を持つ。

| 状態 | 候補数 | 意味 |
|---|---:|---|
| known | 1 | この文書の観測として確定した値 |
| ambiguous | 2 | 外部で明示された二つの読み候補 |
| unobserved | 0 | 対象項目が観測・記述されていない |
| unreadable | 0 | 対象項目の読み取りができなかったと外部で指定 |
| conflict | 2以上 | 追加情報が既知値・候補と食い違い、解決されていない |

knownは外界の真実を保証する意味ではない。unreadableは、数値パケットそのものが破損して復元不能な状態とは異なる。符号の物理的欠落を、意味上のunobservedに自動変換しない。

時間値は、正規順の事象対に対するbefore／after／unspecified。known＋unspecifiedは「前後関係の明示記述なし」という確定した観測であり、追加質問を要求しない。unobservedは、その項目の観測自体が不足している状態であり、追加情報を要求する。

提示順で非隣接の事象対はknown＋unspecifiedに固定する。推移的な時間推論や非隣接関係の生成は扱わない。数・提示順・事象IDの不確かさ、任意の並べ替え、四事象以上は対象外。

## 入力経路と情報境界

1. 完全な制御文一つを既存SS読解器で読む。
2. 一項目だけ異なる完全な制御文二つを、外部から明示された読み候補として読む。その一項目をambiguousとする。
3. 構造化した観測JSONを入力する。欠落・読み取り不能・矛盾を含む状態はこちらで指定する。

二つの読み候補は、同じ事象数・同じ提示順で意味項目の相違が一つだけ必要となる。複数箇所の相違は拒否する。自然文中の曖昧さを自律的に発見・列挙する仕組みではない。複数の未知項目を含む構造化観測は扱えるが、主評価は一項目、二項目は補助検査に限定する。

生成器に渡すパケットはschema、model_fingerprint、dimension、real、imag、eligible_for_inferenceの六項目のみ。観測JSON、教師、原文、対象アドレス、候補集合、事象数を通常メタデータで添付することは禁止する。これらは数値信号から復元する。検査用のrecoverやinspectの出力を、生成器へ横流しする必要はない。

## SS表現

v0.1由来の事象ID・役割・値・時間対の位相符号に、アドレスへ結合した観測状態と候補数の符号を追加する。候補は同じ重みで重畳する。候補の重みを学習・確率推定する実証ではない。

```text
x = (COUNT(n) + Σpresence(event) + ORDER(presentation)
     + Σaddress [ADDRESS * STATE(state)
                  + ADDRESS * ARITY(candidate_count)
                  + Σcandidate VALUE_BOUND_TO_ADDRESS(candidate)]) / sqrt(3)
```

候補数と状態もSS信号の中にある。復元時には相関で状態・候補数を読み、指定数の候補が十分に支持され、除外された候補が弱いことを検査する。MIN_SCORE=0.65、MIN_MARGIN=0.25、MIN_PRESENCE=0.65、MAX_RESIDUAL=0.20は継承する。除外候補の相関上限は1−MIN_SCORE=0.35。相関は確率ではない。閾値や符号は固定・手設計である。

全体の再構成残差も確認する。復元に失敗した場合はabstainとし、不明項目だけを推測して完成文を返さない。

## 確認対象と生成

inspectはSSから復元した、known以外のアドレス・状態・候補を全件返す。最も情報価値が高い質問を学習で選ぶ能動選択ではない。主評価は未確定項目が一つなので、その一つを特定できるかを測る。

未確定項目が一つでもあれば、generateはneeds_informationを返し、textフィールドを含めない。全項目がknownになった後だけ既存SS語彙・語順・時間表現記憶を照会して文を生成する。新しい意味項目を補って完全に見せる処理はない。

## 外部追加情報と局所更新

追加情報は以下の固定形式。

```json
{
  "schema": "plm-ss-local-update-02",
  "packet_sha256": "対象となる数値パケット全体の正規化JSONのSHA-256",
  "target": "event:1/subject",
  "value": "entity:由紀",
  "operation": "supply"
}
```

| 操作と前状態 | 動作 |
|---|---|
| supply：unobserved／unreadable | 外部値でknownにする |
| supply：ambiguousの候補内 | 外部値でknownにする |
| supply：knownと同じ値 | 変更しない |
| supply：knownと異なる／候補外／既にconflict | 候補を残してconflictとする |
| resolve：conflict | 外部から明示された、既存候補の一つへ確定する |
| revise：known | 外部から明示された改訂として値を変更する |

resolveで候補外を選ぶことはできない。必要ならまずsupplyで候補を追加し、改めてresolveする。未知語や不正アドレスは拒否する。未確定のままreviseで飛び越すことも拒否する。

操作名は外部が与える意思表示であって、教師の信頼性・権限・真偽を認証する仕組みではない。ハッシュは対象内容と版の一致検査であり、暗号署名ではない。同じ内容・同じ数値の二つの文書インスタンスを区別する世界IDも含まない。

訂正は受け取った実際の数値ベクトルへ次の差分だけを加える。

```text
x_new = x_received + (CELL(target, new) − CELL(target, old)) / sqrt(3)
```

全文書を新しい正解JSONから再符号化して置き換える操作ではない。訂正後を復元し、対象以外の項目、事象数、提示順が保持されることを確認する。事後条件に失敗した場合は新しいパケットを返さない。元パケットは変更しない。

## 保証しないこと

候補内の誤った教師を与えると、その誤りを確定・文章化し得る。知らない事実をこの系だけで検証することはできない。相関値の高い候補やSS-activeの補助支持を、外部教師の代わりに真実として扱わない。

今回の更新は文書状態だけに作用し、言語モデル・共有記憶の学習係数は不変。新しい照会へ訂正が自動で残るとは言わない。P1部分観測、S1実チップ列・同期、自由長文、照応、省略、因果推論、学習済み質問選択は未実装。`eligible_for_inference=false`。
