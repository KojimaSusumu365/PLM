# PLM：SS型言語処理系への重点移動

記録日：2026-09-07

## 決定と実施状態

ユーザーの指示により、開発の主軸を「SS型の表現・演算・記憶・学習で動く言語処理系」に移す。
目標は、読解・意味処理・文章生成の主要な判断を、符号上で実行することである。
単に既存の解析器や生成器の出力をSSで伝送することは、この目標の達成に数えない。

重点移動の決定時点では開発方針と次の実証計画を反映し、その後、PLM-L1 v0.1の実装・学習・評価を実施した。末尾の実施履歴を参照。
以下の技術的な範囲・順序は、この決定に沿う実装案であり、性能の保証や実証済みの成果ではない。

## 既存成果の扱い

- P1 v0.2とS1 v0.2、およびそれ以前の配布物・検証結果を変更せず保持する。
- P1のPhase表現、結合、相関、部分観測・干渉対策を再利用候補とする。
- S1の明示チップ列・拡散・逆拡散・同期は接続基盤として保持する。
- 分数チップ同期、時計ずれ、帯域・RF条件の拡張は、当面の主開発経路から外す。必要性が生じた時点で再検討する。
- 過去のリリース文書に記された「次の検討」は、そのリリース時点の記録として残す。今後の優先順位には本書を適用する。
- C2/R1の観察・出典・否定・仮定・隔離の境界を保持する。今回の重点移動は、既存R1の推論開放やConcept更新の承認を意味しない。
- 学習実験は独立した実験用モデル・記憶で行い、既存の観察台帳を自動変更しない。

現行P1の符号回復は、外部から役割・アドレス・候補集合を指定する方式である。
これは新方針の土台だが、生の文章から構造を発見する処理や、自由な文章生成を実現済みとは扱わない。

## 「SS中心」の判定基準

コード行数の比率ではなく、主要な言語判断がどこで実行されるかを監査する。

| 領域 | 符号上で担う対象 | 許容する補助処理 |
|---|---|---|
| 表現 | 語、役割、個体、出来事、順序、否定・仮定の範囲 | 文字入出力、語彙ラベルの表示 |
| 演算 | 結合・逆結合・重ね合わせ・順序操作・相関・候補更新 | 数値演算ライブラリ、反復制御、資源制限 |
| 記憶 | 構造化された情報と連想対応の格納・検索 | ファイル保存、モデル版管理、監査ログ |
| 学習 | 語・構造・意味の対応を、経験と誤差に基づき更新 | データ分割、評価用正解、再現用seed管理 |
| 読解 | 入力から役割・構造・状態を選択する | 初期語彙、境界を明記した文法知識 |
| 生成 | 意味と生成状態から構造・語・停止を選択する | 最終的な文字列化 |

Phase空間の意味演算と、チップ領域の拡散・逆拡散は区別し、各処理の実行領域を明記する。
Phase/VSA型の演算を導入しただけで「全処理が明示チップSSで実行された」とは主張しない。
外部LLM、従来パーサー、全文テンプレートは比較用には使えるが、それらが主要判断を代行した結果をSS中心の成功に数えない。

## 最初の実証：学習を含む限定日本語の読解・生成

小さな公開語彙と制御された日本語文法を対象に、入力文から意味符号を構成し、その符号から別表現を生成する一往復を作る。
最初から自由長文を目指さず、役割の入れ替え・否定・仮定を区別できる範囲を明示する。

### 開発順序

1. 表現・演算契約：識別用の固定符号と学習される意味・連想情報を分離し、順序・役割・出来事・否定範囲を定義する。相関値を確率や真実性と混同しない。
2. 記憶・学習：学習データから少なくとも語と役割・構造の対応を更新できる連想記憶を実装する。登録辞書だけの方式と、学習で得た部分を区別する。
3. 読解：語列の符号から構造候補を生成・更新し、意味状態を選択する。正解の役割や出来事の割当てを入力として渡さない。
4. 生成：回復した意味符号と生成目的から、構文・語・助詞・停止を選択する。原文参照や全文検索を使わず、部品を組み合わせる。
5. 独立採点・接続：読解と生成を独立した評価基準で採点し、意味処理が成立してから既存S1経由との比較を行う。

初期の一般文法・語彙はモデル知識として明示する。手作業の規則を符号化しただけの場合は、その部分を「学習済み」とは表現しない。
長文の内容計画、複数文照応、一般推論は後続段階とし、初回の達成条件には混ぜない。

### 情報境界

- 読解器の入力：文章、公開仕様、学習済みモデル、許可された記憶。
- 生成器の入力：読解器が出力した意味符号、生成目的、公開語彙・生成モデル。
- 生成器へ渡さないもの：原文、原文を含むメタデータ、評価者の正解構造、正解の出力文。
- 評価者専用：正解の役割・状態、意味同値性の基準、正解文例。正解文例との文字列一致だけを成功条件にしない。
- 公開候補語彙は許容するが、評価正解から候補を絞り込むことはしない。
- 人間向け監査ログを、生成側へ正解構造を迂回供給する経路にしない。

### 事前に固定する評価

- 読解：役割、否定、仮定の正確さと、主客逆転などの対照文を区別する能力。
- 生成：意味の保持、役割の誤交換、否定・仮定の脱落、根拠のない情報追加、文法適合性。
- 学習：更新前後・更新無効化との比較。学習語彙内の未見の組合せを評価に残す。
- 記憶：保持量・階層深度・干渉を増やした場合の劣化、未知語・曖昧入力・容量超過に対する保留。
- SS演算の寄与：役割結合や順序操作を無効にした比較。比較方式にも同じ語彙・学習データ・計算予算の条件を明示する。
- 独立性：同じ読解器で生成文を読み直す検査だけで合否を決めない。別実装の制御文法による採点も、自然文の人手独立評価とは区別する。
- 再現性：学習・開発・評価を分離し、評価前にデータ・方式・閾値・予算を固定する。数値合格基準は未設定であり、未知評価の前に具体化する。

## 次の成果物と到達点

最初の実装対象「SS型言語コアの最小実証」は、ユーザーの実行指示によりPLM-L1 v0.1として具体化した。
成果物は、演算仕様、実験用記憶と学習器、限定文法の読解器・生成器、固定評価プロトコル、失敗例を含む結果報告を想定する。

目指す到達点は「限定条件で、学習を伴う符号操作により読解・生成が成立すること」である。
一般自然言語の理解、自由長文生成、真偽判断、無制限の記憶容量を証明する実験とは位置付けない。

## 実施履歴：PLM-L1 v0.1

「SS型言語コアの仕様と最小往復実証」を実装し、ZIP展開後の検証まで完了した。
6人・4動詞・2語順・肯否/仮定の4状態について、教師付きの位相連想記憶を用いる。
未学習の組合せ192文×8符号seedで意味完全一致1536/1536、意味保持生成3072/3072、範囲外入力の受理0/248。機能テスト47件、数値受入88項目が合格。
生成器には原文を渡さず、教師コードを配置しない別プロセスでも動作を確認した。
ただし、教師文法・状態注釈は手設計であり、自由作文・自律的な構文獲得・S1同期受信器との統合は未実施。
低次元/高負荷の別連想記憶試験では誤回復・誤受理があり、容量に応じた保留制御と教師依存性の低減を次の検討課題とする。次版の実装はまだ開始していない。
結果と限界は `PLM-L1-v0.1/results/RELEASE_DECISION.md`、配布検証は `PLM-L1-v0.1-VERIFICATION.md` に記録した。
